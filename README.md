# FengZaiY · 个人管理系统

Windows 本地个人管理系统：知识与笔记、资料管理、账号与订阅、财务管理和任务管理。每台电脑使用独立 SQLite，通过加密目录交换不可变修改记录和原件；云端文件历史与保留交给百度同步空间。

账号非秘密信息与独立密码库分开，密码库支持主密码、一次性恢复密钥、自动锁定及密文同步。财务支持收支、转账、退款、分类预算、资产负债、手工外币汇率和 CSV；任务为项目与子任务清单。统一“修改记录”可对用户和 Agent 操作整批撤回，后续变化或引用会阻止直接撤回。

当前支持至 **format 8**：含新命名链接或导图元数据的内容使用 format 8，参与同步的电脑须统一更新。系统与 MCP 服务器名统一为 **FengZaiY**，内置 Skill 的技术标识为 `fengzaiy`，工具前缀为 `FengZaiY_`，新链接为 `fengzaiy://`。旧工作区与链接兼容读取，系统不会因改名新建第二套资料；已有安装升级识别码保留。旧资料迁移须在“资料管理 → 迁移旧资料”预览确认。详见 [命名迁移说明](docs/plans/2026-10-27-fengzaiy-naming.md)。

**内置 AI 对话和模型管理已取消，旧对话、模型及费用历史按已确认规则清理。** 日常开发只交付源码、预览与测试，不生成安装包。

## 运行与验证

需要 Node.js 24。`npm ci` 安装依赖；`npm start` 启动开发桌面；`npm run build` 后 `npm run dev` 启动仅本机的浏览器预览。预览默认端口 4317，可通过 `PORT` 修改；`FENGZAIY_DATA` 选择本机资料目录。

- `npm run check:project`：项目结构与文档检查。
- `npm test`：核心、同步、恢复及外部 Agent MCP 测试。
- `npm run test:personal`：五板块、表单保留、财务、密码库与窄窗口界面验收。
- `npm run test:personal-desktop`：隔离桌面下的锁屏、剪贴板和多板块退出检查。
- `npm run test:ui`、`npm run test:libraries`、`npm run test:agents`：界面回归。
- `npm run test:assets`：资料搜索、属性、引用保护、批量管理、回收恢复及窗口布局。
- `npm run test:dedup`：重复导入复用、独立导入、合并预览及引用/恢复保护。
- `npm run test:trash`：清空回收站的范围、确认、取消、引用保护、过期确认与窗口布局。
- `npm run test:asset-previews`：真实图片/静止视频缩略图、按需加载、离开清理和筛选文字完整性。
- `npm run test:asset-storage`：实际本机目录、位置复制、缺失状态、目录筛选和知识库隔离。
- `npm run test:hierarchy`：库内层级、目录移动、归类及本地文件整理。
- `npm run test:rich`：正式笔记富内容、媒体播放、图表与画板回归。
- `npm run test:mindmap`：思维导图画布、主题编辑、快捷键、拖动、折叠、保存重开及源文本兼容。
- `npm run test:editor`：文件拖入、内容块拖动缩放、横排/纵排及自动保存、失败和冲突保护。
- `npm run test:experience`：浮动工具、快捷插入、目录/阅读设置、粘贴/复制、引用/备注、查找与历史差异。
- `npm run test:storage`：存储位置、未保存保护、取消变更和预览重启迁移。
- `npm run test:desktop`：隔离的开发桌面验证，不打包。
- `npm run benchmark`：本机性能检查，不代表所有设备。

打包仅在用户明确安排的独立任务中执行 `npm run dist` 和 `npm run test:packaged`。旧安装包不包含此后的源码变更。

## 笔记与外部 Agent

外部 Agent 仅通过本机 MCP 接入。在“外部 Agent”启用连接、生成独立凭证，并复制 MCP 地址及客户端配置；有效凭证可读写全部知识库、敏感资料及非秘密个人业务；密码和恢复信息不开放，确认入库、撤回、永久删除与系统管理仍由界面操作。详见 [MCP 接入](docs/agent-mcp.md)。

授权外部 Agent 后，可以让它结合当前正文、新增资料及整理偏好，提出笔记内容、知识层级和出处整理方案。在“整理方案”查看内容并按需部分确认；不满意的部分交给 Agent 局部重做。笔记仍使用普通正文编辑器，保留图片、视频、公式、图表、原附件和修改历史。

交互阅读功能及专用页面运行代码已移除。更新后的程序在启动和导入旧数据时清理历史页面定义，保留正文、附件、出处、版本标识及草稿确认结果。仅包含退役转换的同步使用 format 6；新增个人业务、修改批次和集中资料使用 format 7，所有同步电脑须更新后使用；安装版需要后续发布更新。云端历史及未知副本不在本次自动清理范围。

## 资料管理

进入“资料管理”，按资料集合、原知识库关联或全部范围查看资料；顶部搜索名称、原文件名和标签，列表可按类型、本机状态、引用情况及相同内容筛选。点击资料名称查看详情和引用位置，铅笔按钮编辑名称、标签、敏感标记及允许调整的知识库归属。

页面显示工作区根目录及可展开的“本机目录”。目录来自附件的实际本机绑定，点击目录筛选其中及下级目录的资料；目录数量覆盖当前筛选结果的所有分页。列表名称下显示存放目录，详情可复制完整文件路径及所在文件夹。笔记资料、共享资料、回收资料按实际位置展示；未下载暂无路径，缺失文件保留已记录位置，工作区外绑定单独列出。这里只读查看，不会因为展开目录而搬移文件；桌面版可沿用“打开工作区根目录”入口。

预览列显示图片缩略图和可解码视频的静止画面，点击进入预览；PDF、Office 等文档目前显示格式封面，不是首页截图。未下载或无法解码的原件明确显示状态。筛选项按窗口宽度换行，特别长的已选标签在下方完整展示。

勾选后可批量添加/移除标签、移动知识库或移入回收站，每批最多 200 项。仍被当前笔记、草稿、方案或回收站内容引用的资料须先处理引用，才能回收或跨库移动。回收不删除原文件；在资料回收站恢复，属性历史也可在详情查看/恢复。显示名称可以整理得更清楚，原文件名和稳定引用保持不变。

界面重复导入同库完全相同的文件时默认复用已有附件，保留原名称、标签和敏感标记；确需独立管理时使用“导入为独立资料”。已有重复项可从“合并相同内容”选择保留项，预览受影响内容后确认：当前引用统一到保留项，标签合并，敏感标记不降低，其余条目进入回收站。未保存、冲突、跨库或无法安全调整的引用会阻止执行。历史和原文件保留，旧历史引用需要时可恢复旧附件，本次合并不释放磁盘空间。

## 回收站

回收站支持按当前知识库或全部知识库清空。点击“清空回收站”先查看可清空与受保护内容，确认后执行；搜索词和分页不会缩小清空范围。仍被引用、有冲突或有未保存编辑的内容会保留。清空结果随正常发布同步，不能再从回收站或修改历史恢复；系统逐项清理经引用及哈希核验的托管文件，并保留可重试进度；未知或被手工修改的文件保留，百度云端历史不由本系统删除。多电脑同步前须更新各设备源码，以识别新增清空标记。

## 正文编辑

插入“思维导图”后直接在画布中编辑；正文中双击已有导图也可打开。双击主题修改文字，Tab 添加子主题，Enter 添加同级主题（中心主题上为主分支）；拖到另一主题上调整归属，Alt＋上下方向键调整同级顺序。支持折叠、撤销/重做、左右/向右布局和分支配色。空白处拖动画布，Ctrl＋滚轮缩放，右下角可适应画布。“保存导图”提交一次正文修改；取消不会改正文。

源文本入口保留原 Mermaid 内容。特殊图标、样式和复杂语法使用源文本编辑，不自动简化；可视化编辑最多 500 个主题、40 层。当前不支持 `.xmind` 文件导入导出、自由主题、概要括号或跨主题关系线。

选中文字显示浮动格式工具；在空段落输入 `/` 搜索插入项，或点工具栏加号。在正文输入 `[[` 搜索引用笔记，默认当前知识库，勾选其他知识库后可跨库选择。悬停内部链接显示摘要；正文下方“引用此笔记”按需列出反向引用。

“正文目录”根据当前笔记的标题生成，与左侧知识体系分开；支持章节跳转、当前章节指示。字号、正文宽度、专注模式和原附件分栏宽度只在本机记住，不改正文内容。

笔记的“原附件”面板支持添加本地文件、关联当前知识库已有资料、编辑资料属性、查看详情与引用、解除附件关联。解除关联只修改当前笔记的附件列表，原件、正文里的引用和其他笔记关联继续保留。

原附件列表中的文件可直接拖到正文，绿色插入线显示落点：图片/视频显示素材，其他文件插入可点击的附件链接。短按仍为预览，拖动到正文边缘会自动滚动，Escape 取消拖动。复用已导入附件，不新增原件副本；插入可撤销，并自动保存。专项验证使用 `npm run test:attachment-drag`。

截图可直接粘贴并导入；外部网页图片不自动下载，未保留的嵌入内容会提示。Excel 的制表符文本可粘贴成表格，表格内可增删行列、合并拆分和复制整表；代码块可选择语言、切换换行并复制（当前不提供语法着色）。

选中文字后添加备注，备注的“定位原文”返回对应文字；相同原文有多处时列出候选，内容已改则提示。`Ctrl+F` 在正文查找并可逐项替换，`Ctrl+K` 编辑链接。修改历史支持基准比较、完整内容预览，以及将勾选内容插回正文后撤销；整篇恢复仍新增修改记录。

## 外部 Agent

1. 自行创建知识库；新用户没有示例领域或预设资料。
2. 打开“外部 Agent”，开启本机访问，选择知识库并生成有期限的凭证。
3. 在“系统设置”导出 Skill，将 ZIP 内的 `fengzaiy` 目录安装到目标 Agent 的 Skill 目录或通过其 Skill 管理入口导入。
4. 在该 Agent 的运行环境设置 `FENGZAIY_AGENT_URL`（授权页显示的接口地址，不是预览页面地址）和 `FENGZAIY_AGENT_TOKEN`。不要把凭证写进 Skill 或笔记。
5. Agent 每次工作先调用 bootstrap，读取最新授权、协议和偏好；提交的整理方案在 FengZaiY 中预览、局部修改并部分确认。

默认权限为读取、收集和提方案。直接改写正式笔记、创建关联、移入回收站和访问敏感内容需要额外勾选。确认入库和修改授权/偏好始终由用户操作。凭证可随时撤销，只在生成时显示，本机仅保存哈希。

接口是本机 HTTP，不是 MCP，不向公网开放。目标 Agent 需要本机联网和 Node 24 客户端能力；纯云端 Agent 不能直接访问另一台电脑的 127.0.0.1。不要为接入直接暴露端口。

Skill 的维护源是 [SKILL.md](skills/fengzaiy/SKILL.md)，协议见 [API 文档](skills/fengzaiy/references/api.md)。长期需求基线与应用一同维护；明确的新偏好可在“系统设置 / 整理偏好”保存，形成可同步的历史版本。已安装副本每次工作从系统读取最新指引，不会后台改写其他应用目录。

## 笔记知识体系

知识库是笔记根节点。选择知识库后，左侧“知识体系”呈现笔记上下级关系，最多 16 层；每篇笔记可同时有正文和下级笔记。点击笔记旁的加号或正文上方“新建下级笔记”，即可增加下一层；“调整笔记层级”可选择上级或移到知识库顶层。标题直接在正文编辑，标签独立使用。存在下级（含回收站或待确认方案引用）时不能删除上级，不会连带删除内容。

文件夹管理由后台完成，前端不需要建文件夹。系统在对应知识库文件夹内按笔记层级存放当前完整 JSON、正文和引用资料；多个笔记共用的原件放在共享资料位置。数据库和完整修改历史仍由工作区根目录统一管理，本地正文文件不是自动导入入口或独立备份。

外部 Agent 可结合新知识点和已有笔记提出概览、子笔记、内容融合及上下级方案。在“整理方案”查看归属、理由与正文，勾选满意部分确认；依赖尚未创建的上级时需一起选择或先确认上级。内置 AI 对话仍不提供，理解和推理由用户选择的外部 Agent 完成。

原件整理先复制校验，再切换本地绑定，最后清理无引用的系统旧副本；保留外部来源和用户额外文件。后台维护失败可在“系统设置 / 本地存储”重试，不撤销已保存笔记。旧文件夹结构兼容转换为概览笔记，历史保留。未下载原件保持缺失状态。各电脑须更新后再同步 parentNoteId 新字段。

## 正式笔记

编辑工具栏提供六级标题、任务列表、文字高亮及链接。“插入内容”支持图片、视频、表格、高亮块、贴纸、LaTeX 公式、Mermaid 图表和无限画板。表格支持增删行列、合并拆分；图表通过源文本编辑并预览，画板支持对象、文字、箭头、自由画笔、拖动、缩放和撤销。

本地文件可直接拖入正文，图片/视频直接显示，其他文件插入附件链接。内容默认适应编辑区，不带外框或底部编排工具条；标题位于内容内部下方，编辑/移除按钮在悬停或键盘聚焦时浮在右上方。长按内容一秒后拖动，上下落点调整顺序，左右落点并排；任意边或角可缩放，Escape 取消手势。横排在空间不足时换行，悬浮预览只在拖动中显示。浏览器单文件上限 128 MiB，更大的文件使用桌面版；不导入整个文件夹。

停止编辑约 1.5 秒后自动保存，也可点击保存或使用 Ctrl+S。保存按钮显示待保存、保存中、已保存、失败或冲突。保存期间的新输入继续保留；失败或出现并发版本时暂停自动重试，用户可手动重试或确认并发分支。

链接可选择系统内笔记/资料、附件或 HTTP/HTTPS 网址。本地文件直接链接只在桌面版绑定和确认打开，路径不随笔记同步；另一台电脑需重新关联。浏览器可导入文件为附件。视频实际可播放的编码取决于 Chromium，缺失或不支持的原文件保留占位。

Markdown 导出保留富内容块的源数据，但不打包原文件，第三方阅读器不保证还原这些块；完整资料接收使用同步清单及对应原件。两台电脑都需更新源码后再编辑新增富内容，避免旧编辑器丢弃未知块。

## 数据同步与恢复

“系统设置 / 本地存储”显示系统工作目录（根目录），提供“选择或修改根目录”。选择空目录时先确认迁移当前资料；选择包含工作区的目录时先确认切换，不会静默创建空白资料替代当前知识库。“迁移到新目录”和“打开已有工作区”入口继续保留。变更须确认，重启后生效；迁移保留原目录，复制和校验失败继续原工作区。原目录是迁移前副本，请勿与新目录同时打开。

新建知识库会在根目录下建立同名文件夹，非法字符会安全替换，同名外部目录或保留名称会避让，不覆盖其他文件。文件位置由后台管理，工作根目录在系统设置查看。改知识库名称不会自动重命名根文件夹；删除或恢复知识库也不会物理删除目录。

笔记正文、版本与回收站仍保存在根目录的 `knowledge.sqlite`；新原件按哈希进入 `.fengzai-y/materials`，知识库目录保留正文投影和稳定引用；接收未完成的临时文件位于 `received-objects`。桌面 Markdown、CSV、Skill 和 PDF 导出默认保存到独立的 `.fengzai-y/exports`，保存窗口可另选位置；浏览器预览沿用浏览器下载设置。财务及密码不会自动生成明文投影。文件夹不是单独数据库，也不是可直接打开的独立工作区；手工放入文件夹的文件不会自动入库。不要手工重命名或搬动应用管理的文件夹。

桌面版和 Windows 浏览器预览均弹出系统文件夹选择窗口，无需复制目录路径。选择后仍须检查目录并确认；取消选择不改变原位置。桌面版提供“重启并应用”；浏览器预览保存变更后，需要关闭并使用相同启动参数重新启动预览服务，刷新网页不执行迁移。预览和桌面凭据加密环境不同，不能直接互开工作区；跨环境转移资料使用同步清单和同一配对密钥接收。请勿把工作区放入网盘同步目录，迁移前关闭使用这些目录的其他实例，包括旧版本。

每台电脑使用独立 SQLite；网盘搬运加密版本记录，不同步运行中的数据库。并发修改保留双方，不按最后上传覆盖。删除进入回收站，历史恢复创建新版本。

当前采用 v3 全工作区最新内容同步，不需要 Git，不再提供整库版本提交和本地独立备份。笔记每次保存自动保留修改记录，可通过笔记“历史版本”查看并恢复，恢复本身也留下新记录。

在“多电脑同步”先查看空间预估，再发布当前内容。系统冻结已保存资料，显示新增占用、可用空间和批次规划；达到批次上限或空间不足时暂停。可确认客户端上传、在百度客户端仅释放中转副本，然后继续。发布期间的新修改留待下次发布，不改变当前任务。

新电脑配置百度同步目录与同一密钥，下载后点击“拉取最新内容”即可一次合并各设备最新清单，无需提交设备版本或回放发布历史。所有已导入原件（含大视频、独立素材及回收站）纳入；外部网址和仅有本机路径链接的文件不自动抓取。接收保存分块组装进度，重启先复核已组装部分再继续。非主力机可明确只导入笔记和索引，缺少的原件标为待下载。

主力机保留原件；其他电脑释放原件需明确确认、当前主力机文件回执、无未发布修改或使用/保留引用。中转密文只能通过客户端“仅释放本地”处理，系统不会普通删除同步文件。批次控制不等于零重复占用。新电脑需独立授权 Agent，配对密钥须另行保管。

百度同步空间作为已选定工具使用，管理云端文件历史。应用负责清单与原件匹配、冲突和完整性；“生成交接文件”不等于上传成功。恢复百度旧清单仍需要对应对象和密钥；在已有工作区拉取旧清单不会清除较新修改。旧 Git 仓库和独立备份包保留，当前入口已移除。旧电脑须升级并发布一次 v3，详见 [当前协议](docs/decisions/0006-current-content-sync.md) 和 [系统同步验收](docs/baidu-acceptance.md)。

新增 `agentPreferences` 共享实体后，两台电脑都需使用支持它的新源码构建。旧知识、版本和备份兼容，不重建数据库；旧构建不能导入新偏好实体。

## 当前边界

系统提供富文本、表格、出处、附件、备注、草稿、整理方案、历史和回收站，以及 Markdown 导出/PDF 打印。完整结构化资料由同步清单与原件共同恢复；Excel 专题导出尚未实现。

资料提取、OCR、转写、翻译和知识体系设计由外部 Agent 及其工具完成，系统不宣称自身自动具备这些能力。模型选择、付费确认和费用由外部 Agent 管理，FengZaiY 不估计其账单，也不限制其已有的操作系统权限。
