# StudySelf

Windows 本地知识工作区，首版实现多电脑同步所需的数据层、客户端、设备独立模型配置与独立备份。

**当前为 0.1.0 验证版。自动化双目录测试不等于百度网盘真实双机验收通过。正式资料投入前，请完成 [双机验收清单](docs/baidu-acceptance.md)。**

## 运行

- 安装包：构建后位于 `release/StudySelf-0.1.0-Setup.exe`。
- 开发桌面：`npm install`，`npm start`。
- 本地浏览器预览：`npm run build`，`npm run dev`，打开终端给出的本机地址，默认端口 4317。
- 单元与双目录集成测试：`npm test`。
- 浏览器端到端测试：`npm run test:ui`。
- 原生桌面验证：`node scripts/test-desktop.mjs`。
- Windows 安装包：`npm run dist`。
- 打包后验证：`node scripts/test-desktop.mjs --packaged`。
- 一万条笔记性能检查：`node scripts/benchmark.mjs`。

需要 Node.js 24 或兼容的较新版本。安装后的桌面程序自带运行时，不需要另外安装 Node.js。
升级方式为运行新版本安装包，沿用同一应用标识及用户数据目录；当前没有在线更新服务器或自动更新。

## 已实现

- 富文本笔记、表格、来源附件、独立备注、草稿、可恢复删除、历史恢复。
- 多工作区标签、领域与对话范围隔离、未保存编辑的本机暂存、显式接续其他设备工作区。
- 独立 SQLite 数据库、不可变版本、父版本依赖、幂等导入、并发冲突和人工融合。
- 用户指定同步目录；AES-256-GCM 加密传输包；小附件优先；加密接收回执。
- 两台电脑可错开上线；不借助共享数据库或云端文件锁；文件夹中的文件消失不产生知识删除。
- 待确认方案的部分接受，剩余内容留待修改；入库时验证目标笔记是否已有更新。
- 大文件稳定内容标识、缺失提示、下载后的哈希核验、本机长期保留标记。
- 8 家官方服务、硅基流动和本机 Ollama 配置入口，自定义服务商；共享模型目录、不共享密钥。
- 文本模型调用、费用预览、独立对话、双模型比较、请求去重、实际返回 Token 与估算费用分离。
- Ollama 已安装模型及本机状态检测；不自动下载、安装、迁移或切换模型。
- 独立备份、完整性校验、非破坏性合并恢复；大文件手动补全或桌面空闲两分钟后补全。
- 本地 Markdown 导出及 PDF 打印。结构化完整导出以版本化备份为准。

## 数据边界

安装版数据位于 Electron 的用户数据目录下 `workspace`，界面可读取当前路径。开发预览默认写入项目 `.local/preview`，测试只写 `artifacts`。

本机数据库、设备身份、API 密钥、Ollama 地址和配对密钥不能放进网盘同步目录。安装版密钥使用 Electron safeStorage / Windows 本机加密；开发预览使用本地密钥文件，仅供本机开发测试。不得把整个开发数据目录当共享目录。

同步包加密；**独立备份目前为可检查的明文 JSON 与原文件**，不含设备密钥和 API 密钥。备份只应放在自己的私有存储中，按需要另行加密。恢复后本机模型连接与密钥需重新配置。

同步指纹应在两台电脑一致。配对密钥请通过独立安全途径交接；它授予该知识库的读取与写入能力。只有受信任的自己的电脑才能参与同一配对组。

本地模型是否已安装以本机检测为准。Ollama 的云端型号不会仅因其出现在本机目录就被认定为本地执行。敏感笔记及引用中的敏感标记阻止云端请求。

## 百度网盘与状态

本程序没有绕过百度账号授权、调用不公开接口或使用 Cookie 模拟登录。用户需在官方客户端中配置自己的同步空间。

“等待客户端传输”只表示传输文件在本机目录中生成；“另一台已接收”来自另一实例生成的有效回执。两者均不等同于全部附件已下载，更不等同于百度网盘的上传完成声明。

配对目录只应容纳 StudySelf 的专用传输文件。小附件上限为 16 MiB；更大的附件只同步元信息，由用户在官方客户端获取后关联。客户端的选择性同步和按需获取仍需账户侧实测。

独立备份输出目录需要另行纳入官方客户端的备份/上传范围。StudySelf 不能直接核验其上传完成状态，也不会显示“已完成网盘备份”。

## 当前限制

- 未完成实际百度网盘双机验收；没有使用用户网盘、账号或付费 API 进行测试。
- 服务商预设是可配置接入入口，不是已完成逐家调用认证。模型名称、价格、地区可用性、接入点 ID 由实际账号决定。
- 文本 API 当前支持 OpenAI-compatible Chat Completions、Gemini generateContent 和本机 Ollama；不兼容接口需要新增适配，失败不自动换模型。
- 费用中心不接入服务商结算账单，不进行汇率换算，也不保证跨电脑未同步期间的全局硬预算。未知用量/超时费用需在服务商处核对。
- 不自动做整套视频课程提炼、OCR、语音转写或知识体系重构。当前整理方案支持输入、预览、局部修改与确认；这些进一步的学习 Agent 能力不属于本次同步方案的已验收范围。
- 不内置百度官方客户端，也不自动配置其目录；原文件下载控制权仍在官方客户端。
- 网盘传输记录暂不自动压缩或清理，避免未上线电脑丢失历史。大型长期知识库需要后续的带设备确认的快照与保留策略。
- 安装包未进行商业代码签名，Windows 可能显示未知发布者；不能以此版本直接对外宣称生产级交付。
