## Accepted boundaries

- Device-local Git repositories per library and a separate shared scope.
- Explicit commit, publish, scan and import; never sync SQLite or live Git directories.
- Immutable encrypted bundles and binary attachment chunks in a separate v2 namespace.
- Primary keeps current originals. Secondary eviction requires the current primary's
  content-verified acknowledgement, explicit confirmation and application retention guards.
- Upload confirmation is user testimony, not API verification.
- Existing data, history and old transport directories remain intact.
