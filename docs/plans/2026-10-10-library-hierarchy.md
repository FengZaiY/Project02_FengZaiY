# 知识库分级与本地资料目录

## 目标与边界

- 知识库继续作为权限隔离边界，库内新增可嵌套的文件夹。笔记、草稿、来源和原文件以稳定文件夹标识归类；标签不替代目录。
- 用户自行创建结构，不预置学科/章节，不自动分类旧资料。未归类、远端缺失目录或结构冲突的内容仍可查找，不静默丢弃。
- 文件夹和归属随现有修改记录同步；本地路径不共享。校验同库归属、循环、重名、非空删除和基础版本。
- 本地数据库仍保存历史与查询数据；增加可重建的分类目录，输出完整笔记 JSON 和正文文件，并把已管理原件校验后放入所属目录。原始导入来源、旧仓库和用户额外放置文件不删除。
- 本地整理先提供显式入口；启用后维护投影。目录投影失败不回滚已保存笔记，显示待整理/错误并允许重试。不把投影当作独立备份，不重新加入 Git。
- 外部 Agent 可读取目录并将已有目录作为方案目标；创建/调整目录及确认入库留在用户界面。更新 Skill 的分级规则。
