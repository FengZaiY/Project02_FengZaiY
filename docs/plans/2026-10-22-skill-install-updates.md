# 外部 Skill 安装更新

## 范围与约定

用户要求减少遗忘外部 Skill 更新的风险，支持半自动或全自动完成。系统设置的 SKILL 管理增加已关联安装：通过原生目录选择关联现有 studyself-organize 文件夹，不扫描其他 Agent、不改连接配置或凭证、不新增第三方 Skill。默认自动检查并提醒，用户可选择自动更新。安装关联、授权模式和恢复副本只留本机，不进入同步或外部 Agent API。

更新仅使用当前应用内置 Skill 及已保存偏好。首次关联预览路径和受管文件，经确认登记；每次更新重新检查目标及版本，拒绝链接、未知安装和过期确认。记录每个受管文件的内容摘要，检测用户修改时暂停自动更新。显式覆盖前展示变更文件并保留原内容；其他文件不改。写入日志先落盘，失败/重启恢复原内容，遇到外部再次修改不覆盖，显示待处理。恢复上一份后暂停自动更新，避免立即覆盖恢复结果。用户可解除关联而保留文件。

应用启动及运行期间定期检查已关联位置。系统设置入口显示待处理数量，设置页显示当前状态、模式、版本、时间及错误。已写入文件不等于 Agent 已重新加载；提示重载或新会话。旧导出与 bootstrap 机制保留，偏好未保存不得作为更新内容。
