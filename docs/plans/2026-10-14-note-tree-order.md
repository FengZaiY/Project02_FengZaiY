# 笔记同级拖动与排序

用户确认范围：拖到笔记上缘/下缘成为同级并指定前后顺序；中间继续成为下级，知识库标题继续回到顶层。顺序保留于修改历史与同步，目录继续按实际层级组织。

## 实施

- [x] 加入可选 noteOrder 分数顺序，旧记录无字段仍按标题排列；已排序项在前，后来新增的未排序项按标题排在末尾。首次排序为目标层尚未排序的项建立顺序，后续仅更新移动项。
- [x] 同事务验证源基础版本与目标层快照，写入必要的顺序记录；来源和邻居已变化则拒绝，不覆盖。同步并发保留双方，顺序相同以稳定 ID 决定显示先后。
- [x] 上下插入线、同级落点、无变化提示；与串行自动保存衔接，保留当前/后台编辑与撤销。初始化排序影响其他打开笔记时，仅在基础版本吻合时更新其顺序和基础版本，不改正文。
- [x] 覆盖重开、同步、并发、失败回滚、跨父移动、整分支、真实鼠标与原件目录；188 项核心测试及相关界面回归通过，检查截图。
- [x] 更新约定、架构、Skill 基线/API、状态和验证，沿用原工作区预览；181 条修改记录、17 个实体及 7 个原件保持一致，不生成安装包。

目录不靠数字前缀表达顺序，避免排序触发大文件搬迁。分数使用十进制整数字符串并约分，避免浮点精度耗尽；长度超限明确拒绝，不生成无效版本。旧客户端不支持 noteOrder，参与同步的设备需一起更新。
