# 操作请求误过期与拒绝项隐藏

## 范围

修复外部 Agent 请求的快照校验把 Skill 检查时间当作配置变更的问题；操作请求列表隐藏已拒绝项，保留拒绝回执和幂等保护。不确认真实请求，不改正式笔记，不打包。

## 步骤

- 已完成：检查请求快照、后台 Skill 检查和列表渲染，定位 checkedAt 周期更新被纳入快照。
- 已完成：以实际关联 Skill 和 MCP 提交方案确认请求复现，排除纯检查时间并验证真实变化仍拦截；隐藏已拒绝项。
- 已完成：核心全量、构建、请求/Agent/通用界面、Skill、启动及源码桌面验证，更新记录并核对原预览。首次环境及旧界面定位失败与复核结果见 [验证记录](../verification-agent-request-staleness-2026-10-29.md)。

## 兼容

旧请求仅保存快照哈希，不能证明差异仅来自检查时间，继续拒绝过期请求并由 Agent 重新发起，不直接替换快照。拒绝项只从界面列表隐藏，结果查询和相同 requestId 不重跑保持不变。
