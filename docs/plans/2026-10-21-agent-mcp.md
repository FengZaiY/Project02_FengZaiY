# 外部 Agent MCP 接入

## 范围

在现有本机 Agent HTTP 服务上增加 `/mcp`，使用官方 SDK 的无会话 Streamable HTTP。保留 `/v1/rpc` 兼容脚本；不开放界面 RPC，不迁移凭证、数据或授权，不改用户外部客户端配置。

## 实施

1. 增加官方 MCP SDK 和独立适配层，具名工具复用 AgentAccess 的授权、审计、幂等及偏好版本校验。每次请求重新验证凭证，工具目录按授权过滤。
2. 外部 Agent 页面展示 MCP 地址及不含真实凭证的 Codex / 通用 JSON 配置，可复制；关闭服务后不显示可用地址。
3. 更新 Skill、API 协议、项目约定和使用说明。MCP bootstrap 返回最新规则；来源资料不能变成服务器权限。
4. 使用隔离资料验证标准客户端握手、工具发现、读写/重放、冲突、授权边界、撤销/过期、请求大小和异常协议；验证浏览器界面及源码桌面。
5. 更新验证记录及预览。仅交付源码和预览，不提交、不推送、不打包。

## 验收

- 支持 MCP 客户端连接并提交待确认整理方案；用户确认后才入库。
- HTTP 与 MCP 使用相同权限；不会暴露系统方法或返回本机路径和凭证。
- 不引入公网监听、宽泛 CORS、服务器自动模型调用或隐式重试付费推理。
- 基于标准客户端实测，不冒称已完成每个第三方桌面产品的联调。
