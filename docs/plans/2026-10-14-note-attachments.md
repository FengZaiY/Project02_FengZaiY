# 原附件面板与管理

- [x] 将笔记面板、开关及无障碍名称统一为“原附件”。
- [x] 增加关联已有资料、附件属性/详情、解除关联；复用原有资料接口和串行保存，保留编辑器及未保存输入。
- [x] 隔离验证添加/解除、正文引用保留、保存失败/并发、属性修改、切换范围、预览和窄窗口。
- [x] 更新需求基线、状态与验证记录；核对原工作区后交付静态预览，不生成安装包。

仅改变附件关联及界面，不删除原文件、不修改同步协议或扩大外部 Agent 权限。解除关联与资料回收分开，正文引用及其他笔记关联继续保留。

验证发现已有存储层会把正文/来源链接中的附件自动加入 assetIds，因此面板标明引用来源；这类附件须先移除正文或来源链接引用后再解除，不能声称已经解除又被保存流程重新加回。仅附加的附件可直接解除。
