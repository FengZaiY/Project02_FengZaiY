# 修改记录校验修复

目的：修复可选 undefined 字段在 JSON 持久化时消失导致保存成功、发布失败的问题。当前本机桌面与预览各 7 条记录只读检查均通过，尚未取得家里异常记录。不改变现有配对密钥，不承诺已修复未知损坏，不打包。

- [x] 新写入先规范为可持久化 JSON，再校验业务字段并计算哈希；插入前复核实际持久化表示。
- [x] 旧记录仅通过有界的已知可选字段 undefined 重建验证原哈希；保持原 ID、父版本、正文与 hash，不重写数据库或同步对象。无法证明的记录仍拒绝。
- [x] 受信任界面增加修改记录检查；发布/导入报错定位记录，扫描区分文件缺失和校验失败。
- [x] 隔离测试覆盖旧版复现、重启、双向同步、重复导入、冲突与真损坏拒绝；检验权限与资源边界。284 项核心、浏览器界面及源码桌面复验通过。
- [x] 更新约定/架构/验证记录、原预览；只读复核当前资料，保留其他任务的发布修改。事件、heads、附件绑定与配对密钥摘要保持一致。

兼容策略不是批量重算校验值：只在重建的旧表示精确匹配已存在 SHA-256 时认可，JSON 业务内容不变。旧版接收端仍不理解这种历史记录，两端需要更新到包含修复的版本。
