# MCP 全功能与本机确认

用户选择：开放全部应用功能，但密码须本机解锁，删除、授权和系统变更仍须本机确认。此选择替代旧版一律禁止 MCP 使用密码库和系统功能的限制，不授权绕过版本、引用、设备角色或完整性检查。

## 实施边界

- 保留现有具名业务工具，新增固定操作目录、调用及结果工具；只登记应用已有功能，不提供 Shell、SQL 或任意 Service 转发。
- 普通读取直接返回；密码的专用读取要求本机已解锁，不返回主密码、数据密钥或恢复密钥，不缓存秘密结果。初始化、解锁、主密码与恢复配置由本机界面输入。
- 删除及新增管理/维护写入进入本机确认队列；Agent 不能自行确认。队列归属凭证，确认重验授权、偏好、版本和参数摘要；撤销/到期、拒绝、过期、重复及失败均明确返回。
- 确认队列和结果仅本机加密存储，不随同步传播，不写正文或审计日志。秘密不进入一般回执。应用重启后进行中请求不自动重跑。
- 桌面更新等能力沿用原本机流程；预览不伪装具备原生安装能力。工具目录明确可执行、待本机确认和须本机交互的区别。
- 同步 Skill、协议、授权界面和项目约定；仅隔离测试，不对真实授权、秘密、回收站或同步配置试操作。
