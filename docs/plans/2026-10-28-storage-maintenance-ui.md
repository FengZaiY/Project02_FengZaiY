# 资料浏览与存储维护入口优化

用户确认五项：分类/主题主导航、用途集合作为辅助；统一工作区切换；先扫描再分项清理；旧版迁移折叠；仅待处理任务显示重试。

## 实施

1. 保留 materialCollection 身份和接口，仅调整界面名称与层次，不迁移业务数据。
2. 将设置中的存储日常操作和维护扫描拆分，复用已有预览、确认令牌与清理接口。扫描串行调用有维护互斥的接口，每项失败独立呈现，不当作零结果。
3. 高级维护只读检测内部布局与资料迁移，按需要展示；扫描结果明确工作区、可释放空间和保留原因，不把接收目录大小当可释放空间。
4. 条件展示重试，保留未保存编辑保护和工作区切换的预览/确认/重启机制。
5. 隔离浏览器回归覆盖分类整理、扫描无写入、异常、清理确认、工作区迁移/切换与窄屏；更新约定、Skill 和验证记录。

本轮不操作正式资料、不提交、不推送、不打包。后端删除保护及传输行为不变。
