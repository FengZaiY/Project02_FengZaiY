# 本机文件导入请求误失效

两张用户截图显示不同PDF导入请求同时因资料/配置变化无法确认。当前所有确认请求绑定全库版本头，先确认一个导入就会使其他导入失效；后台Skill最近检查时间此前已排除，但全库依赖仍过宽。

只为assetImport引入窄范围快照：工作区与存储计划、目标知识库身份/版本、发起授权及偏好。不因其他文件导入/笔记保存/Skill检查失效；删除凭据、到期、撤销及未保存保护保留，其他高风险操作继续原规则。

本机预览检查文件状态并纳入确认令牌。尚未到期、未执行且偏好未变的旧导入请求可显式“重新核对”：参数不变，重新展示当前文件与归属，旧确认令牌作废，再次确认才导入。不向MCP开放重新核对，不自动重试/延长请求有效期。原件缺失、目标无效或授权/偏好变化继续阻止。

用隔离文件验证多请求顺序确认、文件/目标变化、旧令牌、幂等、权限、撤销和过期；界面/桌面及完整核心回归。更新维护与Skill协议，不操作用户截图里的真实文件、不提交/推送/打包。

进度：范围快照、本机重新核对、文件状态令牌及界面已实现；12 项操作核心、398 项完整核心、操作界面和真实 Electron 操作专项通过。协议与维护规则已更新；Agent/Skill/通用界面、启动、源码桌面回归及原预览工作区重启核验通过。通用 Agent 脚本的来源打开改为 Ctrl+单击，适配现有普通点击替换标签规则。详见 [验证记录](../verification-agent-import-2026-10-29.md)。

后续复查：用户反馈同一提示多次出现。只读核实当前运行的安装版 0.1.17 包内仍无范围快照和本机重新核对，不能把源码交付误认为安装版生效。本轮继续补齐导入失效原因、确认失败后刷新预览、文件恢复后的手动刷新，以及关闭弹窗时迟到响应保护；仅刷新预览，不自动重新确认或执行。补充隔离回归和部署差异证据，不改安装包或正式请求。

复查进度：失效原因与预览恢复已实现，13 项操作核心、浏览器重复变化/文件恢复/迟到响应及真实 Electron 回归通过。安装包差异只读留证，预览沿原工作区重启且摘要一致。完整核心 399/399、项目与差异检查通过，结果见 [复查验证](../verification-agent-import-recovery-2026-10-29.md)。源码及预览交付完成，正式安装版生效仍需后续发布升级。
