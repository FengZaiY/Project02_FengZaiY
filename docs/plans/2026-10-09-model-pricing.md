# 自动模型价格

日期：2026-10-09。

## 边界

优先读取可核验的官方公开价格，精确匹配服务地址和模型 ID；不推测第三方、接入点、优惠和复杂阶梯的价格。获取失败时费用未知，仍可配置和确认后调用。手动价格是高级设置中的可选覆盖，本机 Ollama 不要求价格。不生成安装包。

## 步骤

- [x] 检查现有模型、费用、共享数据和界面边界。
- [x] 核验公开来源，实现有界抓取、严格解析、设备本地缓存和失败降级。首个经实抓核验适配器为 DeepSeek，其余未知。
- [x] 接入模型管理、可选覆盖和调用估算；保留价格依据及旧记录兼容。
- [x] 增加模拟接口测试及界面验证。50 项核心测试及三组界面测试、开发桌面通过；真实公开来源抓取通过。
- [x] 更新验证、架构和项目状态，保留现有预览数据；原端口和配置保留，没有生成安装包。

## 验证重点

未知不是零；错误型号、代理地址、页面结构变更、过期和失败不能误匹配。价格请求不带密钥或学习内容。调用按预览时的价格快照计算估算，不改写历史费用。Ollama 云端模型不能误判免费本地推理。
