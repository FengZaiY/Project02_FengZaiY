## 范围与方法

1. 对照五个板块、系统工具、受信任服务入口、MCP 工具及内置 Skill，建立覆盖清单。
2. 在独立测试目录运行本机核心、浏览器、源码 Electron 测试；混合测试文件逐项排除同步、传输、设备配对及退役备份场景，不直接运行包含这些场景的全量 npm test。
3. 审核业务不变量、创建到回收/恢复的闭环、异常和未保存保护；对可复现问题先建立回归证据再修复。
4. 通过实际 MCP SDK 测试核对发现、读写、幂等、撤销及秘密边界；校验 Skill 的协议、示例、客户端、导出及更新能力。
5. 复查桌面/窄窗截图，记录通过、失败修复及未验证项；更新状态和验证记录。若修改后端，交付预览前沿用核实的原工作区重启，检查数据未变化。

## 约束

- 不对正式资料执行导入、删除、付款或密码操作；不更改外部已安装 Skill。
- 不进行多电脑同步、真实网盘联调、安装包构建、签名、安装发布或付费服务调用。
- 源码审查和自动化通过不代表不存在任何缺陷；报告保留验证边界。
