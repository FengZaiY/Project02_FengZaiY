# 正式笔记富内容

日期：2026-10-09。

## 目标与边界

扩展现有 Tiptap 正式笔记编辑器，保留版本、草稿、附件稳定标识及外部 Agent 授权边界。不恢复内置 AI，不打包安装程序，不修改正式资料。

## 计划

- [x] 内容结构与安全：可继续编辑的富内容块、嵌入引用检查、本机文件绑定。
- [x] 编辑体验：多级标题、任务、高亮块、贴纸、图片视频、公式、图表、无限画板、链接。
- [x] 持久化与回归：保存重开、撤销、未保存编辑、授权、同步和备份保留。
- [x] 文档与交付：同步 Skill、协议、状态与实测记录，提供隔离预览。

## 设计

富内容沿用 HTML 正文中的带版本数据块；图表保存源文本，画板保存结构化数据。媒体仅保存附件 ID。本地文件链接保存不含路径的标识，路径仅在当前设备绑定。读取旧历史不重写内容或校验哈希。外部 Agent 从正文独立提取引用，不能靠省略附件列表绕过授权。
