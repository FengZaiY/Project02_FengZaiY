# 整理方案确认状态与待办列表

针对已确认方案长期混在列表、同步状态被误认为确认状态的问题，默认列出待处理方案，提供已确认与全部筛选；逐项进度涵盖笔记与资料整理项。冲突、部分确认及无方案项记录仍保留在待处理。

状态从现有方案项派生，不新增共享字段、不修改方案或已入库资料。服务端先过滤后限制数量，搜索保持所选确认状态；界面显示明确状态及确认进度，同步状态单独标识。全部确认后退出待处理列表，当前详情继续可读。清理至回收站仍需用户显式确认，恢复不会再次入库。

验证覆盖混合方案、资料独立方案、空项、冲突、过滤与分页、部分/全部确认、已确认检索以及已有清理/恢复流程。仅隔离测试，不清理正式数据，不提交、推送、打包。
