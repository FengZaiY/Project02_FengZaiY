# 笔记知识体系与后台目录

## 目标

知识库是笔记根节点，也是本地文件根目录。前端只呈现知识库、笔记和笔记上下级关系，不再提供文件夹管理。本地正文、数据及资料由后台自动维护。外部 Agent 可提出新建概览笔记、归属调整及内容融合方案，用户分项确认。

## 数据与兼容

- 正式笔记使用可选 parentNoteId。稳定标识、基础版本、循环/层数/同库约束和并发异常检查覆盖用户、提案和同步。
- 旧 folder 记录保留，确定性派生为可编辑概览笔记；旧归属转为笔记父级，保留原修改历史，可中断重试，双机重复迁移不会生成两套笔记。
- 提案可以引用同批新笔记，审批按依赖处理；选中子项但未选择未入库父项须明确提示。已有笔记位置和正文均有基础版本保护，局部修改不重做整批。
- 文件系统为可重建当前投影，知识库文件夹直接容纳笔记层级及资料；保留托管文件校验、外部原件保护和失败重试。
