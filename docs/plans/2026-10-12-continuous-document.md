# 连续文档编辑

用户要求正文采用连续文档交互，不使用带框、固定尺寸的编辑空间。本次不复制其他产品的全部功能。

- [x] 普通文字、表格、高亮块和文件链接不再生成可缩放容器；旧容器按内容顺序展开，保留段落、富内容及稳定引用。
- [x] 载入、粘贴、历史阅读统一兼容；仅阅读不产生修改版本，后续编辑通过正常保存保留新版本，旧历史不改写。
- [x] 验证回车、退格、跨段落选择、撤销、长文自适应、旧内容保存重开、媒体及自动保存。
- [x] 更新需求基线、项目规则、架构和验证记录，构建并核对原预览；不生成安装包。

媒体仍保留独立尺寸与纯媒体横排。含普通正文的旧横排改为按阅读顺序纵排，空段落保留为普通空行，不批量删除笔记内容。数据库、同步格式和历史事件哈希不变。

完成证据见 [连续文档验证](../verification-continuous-document-2026-10-12.md)。原预览刷新后当前笔记分支及 49 条历史记录摘要未变化。
