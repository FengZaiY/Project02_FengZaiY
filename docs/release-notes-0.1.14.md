# FengZaiY 0.1.14

## 本轮变化

- 资料原件支持“资料/分类/主题/可读文件名”，笔记层级生成正文与资料引用；原件与笔记移动分别管理，引用身份保留。
- 新工作区数据库位于 .fengzai-y/database；已有工作区可在本机界面安排停写重启迁移，复制校验后切换，旧副本单独预览确认清理。
- MCP 支持统一资料整理方案、依赖与部分确认、分块上传；固定操作目录扩展应用能力。删除、授权、确认及系统变更仍须本机审核，密码接口须本机解锁。
- 更新下载支持暂停、继续及重新下载，校验完整文件后才允许安装。
- 完善纯文本代码块、目录树粘贴、缩进、复制、自动换行及编辑快捷键，保留撤销与保存。

## 升级须知

新增资料分类、主题与原件归属使用 format 9；参与同步的电脑都须升级，旧格式继续读取。内部数据库布局迁移后旧安装版不能继续打开，请使用新版。迁移保留旧副本，不自动清理未知文件或外部来源，不代用户确认实际整理方案。

本版本不承诺自动清理过期上传暂存、分类删除/恢复专门界面或旧导出自动迁移。无法识别格式的纯文本代码须先插入代码块。重启后更新下载需重新检查并手动开始，可复用同文件断点。

## 发布验证

本次测试和附件验证结果在交付报告中记录，不以此前开发结果代替。签名、真实安装、卸载及跨版本升级状态以本次实际验证为准。Release 仅准备草稿，公开前由用户核对。
