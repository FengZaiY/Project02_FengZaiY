# 可读目录与统一整理验证

日期：2026-10-28。Windows、Node 24.16.0、源码 Electron。仅交付源码和预览，不提交、推送、修改版本或生成安装包。保留并存的更新下载、MCP 操作目录和编辑器改动。

## 实现范围

- 原件按资料分类/主题/可读文件名落盘，笔记生成正文.md 与资料引用.md，完整富内容结构放内部元数据。多处引用使用稳定 ID，笔记移动不搬原件。
- 分类/主题、文件名整理共用 MCP propose/materialItems；支持依赖审批、局部重做、过期校验及业务/文件状态分离。新增五项上传工具使用 4 MiB 分块和持久化断点。
- 迁移先复制、校验、持久化再切换绑定，旧托管副本保留供单独清理；外部源、未知文件和手工修改受保护。
- 内部数据库迁移需停写关闭，启动日志可恢复；已迁移工作区缺失数据库不能静默建空库。旧根数据库位置保留防旧客户端误开的说明目录。
- 新共享结构使用 format 9；隔离双目录验证接收后分类/目录重建及重复导入，不把模拟结果等同于真实百度双机部署。
