# StudySelf 0.1.10

日期：2026-10-24。发布准备，正式公开前由用户核对。

## 同步清单占用修复

最新清单替换遇到 EPERM、EACCES、EBUSY 时异步有限重试，最多重试 7 次，计划等待累计 9 秒，期间可暂停。持续失败保留旧清单及冻结任务，提示解除占用后继续，不先删除旧清单、不自动结束百度客户端或修改权限。

界面区分对象生成和清单更新；替换成功才记生成完成，云端上传确认仍独立。临时文件清理失败明确提示，不掩盖原始错误。不改变加密格式或附件同步范围，不保证所有权限/占用问题均自动解决。

## 已确认整理方案清理

全部确认且无冲突的方案可从界面明确清理至回收站，也可查看入库笔记。校验基础版本与未保存编辑，重复操作不增加记录；部分确认方案不自动清理。

入库笔记、原件、草稿及处理结果保留；恢复方案不重复入库。永久清空与远端删除保护草稿依赖的有效确认记录；完整依赖组可按原规则一起清空。新入口不开放给外部 Agent，不自动清理正式资料。

## 兼容与验证

同步格式与事件字段不变；所有同步电脑需更新才能一致执行新增确认依据保护，无法恢复旧客户端已经永久删除的唯一依据。沿用 0.1.9 的仅 MCP 接入及统一凭证范围。

本轮测试、构建和附件校验待执行。实际签名状态及真实安装、卸载、跨版本升级验证范围将据实披露，打包程序启动测试不等于真实安装验证。
