# FengZaiY 0.1.16

## 本轮变化

- 优化当前记录列表、统计和轻量状态查询，先筛选分页再读取正文；查询缓存随事务及当前版本变化失效，不改变冲突、权限与完整性校验。
- 后台目录投影复用未变化项；父级、引用和本机绑定变化继续传播。附件读取及哈希校验移入工作线程，仍使用同一文件句柄并验证读取前后的状态。
- 图片和视频静止帧使用有界会话缩略图缓存，文件身份变化后重新校验；不缓存为永久资料，也不代表原件已上传。
- 普通点击笔记或草稿切换当前标签；Ctrl+单击、中键、右键菜单及 Ctrl+Enter 可明确另开标签。切换先保存当前输入，失败或冲突保留原页，重复打开不重建未变化的编辑器。
- 删除笔记后离开被删除正文，切换其他有效标签或空状态；取消、失败与延迟响应不覆盖新选择。
- 整理方案默认显示待处理，可筛选已确认或全部；进度同时包含笔记和资料项。全部确认退出待处理列表，不自动回收。
- Agent 操作请求隐藏已拒绝项；已关联 Skill 的后台检查时间变化不再使请求误过期，真实内容及配置变化仍受保护。
- 自动更新源改为更名后的 `FengZaiY/Project02_FengZaiY`。

## 兼容与边界

沿用 format 9 和现有内部数据库布局；可重建读取索引仅留在数据库连接内，不改写用户修改记录和哈希。UI 协议升级为 4，页面与后端须一起更新。旧安装版不支持已迁移的内部数据库布局，所有同步电脑应升级至兼容版本。

性能改善以本机隔离样本为依据，不保证所有电脑或全部路径同样改善；全文搜索、首次目录构建和部分业务扫描仍有成本。本次不操作正式资料、百度客户端或外部 Skill 安装。

本版仅准备 GitHub Release 草稿，正式公开须由用户明确确认。签名、真实安装/卸载/跨版本升级及本轮验证结果在交付报告中如实列明。
