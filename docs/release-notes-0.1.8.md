# StudySelf 0.1.8

状态：版本及说明准备完成，用户已安排合并提交本轮修复与版本，尚未打包或创建 Release。

## 本版更新

- 修复修改记录中可选 undefined 字段在 JSON 持久化后消失、导致后续同步校验失败的问题。新记录先规范化为可保存 JSON，再计算校验；插入前重验实际持久化表示。
- 兼容一类旧版 checksum 异常：仅当重建已知可选空字段后的表示精确匹配原 SHA-256 时认可，保留原记录标识、父版本、正文及哈希，不批量重算或跳过校验。
- 多电脑同步新增“检查本机修改记录”，只读统计正常、旧版兼容及异常记录；无法核实的异常显示记录/版本标识并继续阻止同步。
- 已下载内容扫描区分历史对象校验失败和文件缺失，避免把校验错误显示为尚未下载。

## 相对公开版 0.1.6 的其他更新

包含已在本地提交、尚未独立发布的 0.1.7 接收目录功能：系统设置分页查看续传、读取、绑定/链接及待清理状态，目录维护和永久删除收尾安全移除空接收目录，旧原件副本清理保护本机文件链接。未知文件、绑定、续传登记及异常路径保留。详见 [0.1.7 说明](release-notes-0.1.7.md)。

0.1.7 说明中的“未修复 checksum”描述该提交的范围；本版在其基础上加入上述有界修复。

## 使用与兼容

含此类旧记录的同步两端须升级到带本修复的版本。沿用现有同步格式和配对密钥，不重写历史事件、同步对象或哈希。兼容搜索受尝试次数、字节预算及缓存限制，无法证明的记录、未知损坏或篡改继续拒绝处理。

家里电脑的实际异常记录尚未取得，不能据此宣称全部历史损坏已修复。本机只读检查通过也不代表其他电脑或云端全部内容正常；诊断接口不向外部 Agent 扩大权限。
