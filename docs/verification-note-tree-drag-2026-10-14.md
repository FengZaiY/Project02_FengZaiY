# 笔记树拖动与本机目录验证

日期：2026-10-14。环境：Windows、Node 24.16.0、Playwright Chromium，测试数据均为隔离临时资料。

## 行为

- 拖到另一篇笔记上成为其下级；拖到列表顶部的知识库标题成为顶层。“全部知识库”视图使用各库分组标题作为顶层落点。
- 整条下级分支跟随，不增加手工同级排序或跨库移动。落点有高亮和具体提示，循环、跨库、冲突及层数限制保留前后端检查。
- 起拖不改变列表几何位置；拖动期间延后仅导航区域的重建。取消、放到无效区域或伪造外部拖动数据不产生修改。
- 当前/后台打开标签的移动进入同一自动保存队列，保留输入、编辑器实例、撤销和附件预览；关闭笔记使用观察到的基础版本。失败保留正文，撤回未提交的上级意图，不自动保存并发分支。
- 沿用后台 LocalHierarchy：移动后的正文 JSON/Markdown、下级笔记投影及专属原件自动跟随；共用原件保留共享位置。先复制校验并持久化新绑定，之后才清理旧托管副本，外部导入源与额外文件保留。目录维护失败的查看与重试仍在系统设置。
