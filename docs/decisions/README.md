## 新记录约定

使用递增编号 `NNNN-short-title.md`，包含日期、背景、决定、替代方案、后果、验证条件和状态。

状态区分“提议”“已接受”“待外部验证”“已替代”。已有决定被替代时保留历史并链接新记录，不悄悄重写过去的结论。必要时同步修改 [架构说明](../architecture.md) 和 [项目状态](../project-status.md)。
