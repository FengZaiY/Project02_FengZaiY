# 0006: 当前内容同步与笔记修改历史

日期：2026-10-10。已接受并实现于源码；替代 0005 的运行时 Git 与独立备份入口。

## 用户决定

不引入 Git 管理知识版本，不区分整库/单库版本提交，不提供本地独立备份。百度同步空间承担云端保留和文件历史；StudySelf 保存笔记修改记录，用于改错恢复、冲突合并、回收站和出处追溯。

## 实现

每设备只更新自己命名的 `current-<deviceId>.sscurrent` 加密最新清单，避免多设备争抢一个最新文件。每份清单包含全工作区自包含修改历史分块、原件索引、偏好和设备策略。新电脑一次拉取所有已下载清单，合并记录身份及父关系，无需以前的发布或 Git。发布仍是用户明确动作，未保存标签须先处理；已保存并发修改不要求提交，拉取时保留双方。

笔记历史分为不超过约 2 MiB 的加密对象，原件为 4 MiB 加密块，均按内容身份校验。最新清单最后原子替换；文件到达乱序、缺少、损坏时不得完整入库。各设备最新清单合并后，知识记录、文件绑定与导入去重信息同事务保存。

发布空间预估冻结当前资料，报告新增占用、可用空间、64 MiB 保留空间及批次上限。默认每批上限 256 MiB，也可选更小批次。每个对象完成后记录进度；空间不足暂停，继续时重新检查实际可用空间。生成后被客户端仅释放本地的新对象，须有明确批次上传确认才能最终引用；应用从不自行删除中转文件。已知同步对象可复用引用，空间估算不等于网络流量或百度上传进度。

接收使用本机内容寻址的 `.v3.partial` 文件与 SQLite 检查点；每个分块写入并 flush 后保存进度。重启时复核前缀，遇到损坏从首个无效分块重来，不必重新下载已验证前缀。最终校验全文件后才改为原件并绑定。空间不足、暂停和失败保留进度。

## 兼容

- 原数据库、修改历史、稳定 ID、凭据、旧仓库和备份不删除。
- v2 未完成日志可恢复知识记录与附件绑定，旧日志另存本地，不执行 Git 或维护原提交指针。
- 旧传输协议不混写，新协议目录为 `StudySelfSync/v3/<key-fingerprint>`。旧电脑须更新并发布一次，才能为新电脑提供自包含清单。
- 退役 Git/备份模块仅供兼容测试与维护；当前 Service、Electron 与界面不提供 Git 或独立备份方法，也不定时创建备份。
- 外部 Agent 不增加同步、设备或释放权限；用户补充偏好不被源码基线更新覆盖。

## 云端恢复与边界

百度提供文件历史，应用不另建整库版本页面。恢复旧清单仍需要其引用的不可变对象和独立保存的密钥；不假设云端对整个目录提供跨文件事务恢复。空工作区可从恢复后的清单重建；在已有工作区拉取旧清单会合并历史而不清空较新的记录，单篇笔记回退使用修改历史恢复。

云端上传、空间释放由官方客户端负责。中转对象当前不自动清理，所以批次降低单轮新增占用，不保证永久零重复或无人值守释放。主力机历史原件精细释放仍未实现。历史清单恢复不等于远端没有其他设备的新内容。

当前清单上限 32 MiB、每次读取的对象有大小限制，笔记历史整体仍在内存中校验；十万级历史、GB 视频、真实磁盘满盘/断电性能仍需专门测试。暂停在当前分块完成后生效。发布估算失败前没有生成有效新清单，失败信息需要用户按提示处理。
