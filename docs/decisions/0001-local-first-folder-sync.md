# 0001：本地知识库与官方客户端目录传输

记录日期：2026-10-08。
状态：用户已确认实施方向；百度网盘真实双机传输待验收，尚非正式可靠性结论。

## 背景

用户需要在家里和公司电脑接续学习，使用 Windows 独立软件，保留本地原文件。已有百度网盘付费容量，取消手机场景，不新增云服务器。不同设备可配置不同官方 API、第三方服务和本地 Ollama。

## 决定

- 每台电脑独立存储 SQLite；百度官方客户端只传输不可变修改记录和附件，不同步活动数据库。
- 通过版本标识、父版本、校验、加密和接收回执实现最终一致性；保留冲突，禁止最后写入覆盖。
- 删除用可恢复版本传播。附件标识共享，本地路径独立，大文件通过官方客户端获取后验证关联。
- 共享知识和模型目录，不共享密钥、运行环境或已安装模型；任务不随同步自动运行。
- 独立备份与同步分离，允许大文件延后。不能观察的云端上传状态保持未核验。

## 替代方案与取舍

- 直接同步 SQLite 不采用：不能把活动数据库当作普通内容文件跨设备传输。
- 新建云端协同服务不纳入当前授权和部署范围。
- 百度客户端若无法满足关键条件，记录具体限制并与用户讨论替代方案，不自动更换云服务。

## 后果

设备不必同时在线，但一致性取决于官方客户端最终交付完整文件。程序不能把文件已生成等同于网盘上传完成。目录增长、设备确认与历史保留需要后续评估。

本轮备份是明文，虽然排除凭据，仍应存入私有位置并按需另行加密。配对密钥授权参与设备读写同一知识库，需独立安全交接。

## 验证条件

完成 [真实双机验收](../baidu-acceptance.md) 中的错开上线、冲突、中断、附件、模型差异、费用和恢复测试，记录账号限制及客户端设置。自动化双目录测试不足以将本决策状态升级为“已通过外部验收”。
