# 0003：外部 Agent 接管知识整理

日期：2026-10-09。状态：已采用；用户实际外部环境接入待验证。

## 背景

用户取消整个内置 AI 对话与模型管理，要求通过外部 Agent 控制知识系统，并把学习需求维护为持续更新的 Skill。本决定替代 0001 中设备独立模型配置部分，不改变其独立数据库、目录传输与备份策略。

## 决定

移除模型、价格、推理和聊天运行模块。保留旧实体格式和历史，不删除用户资料，不执行历史任务。

提供默认关闭、仅回环网络的独立 HTTP API，在桌面/预览共用同一实现。按 Agent、知识库、有效期和敏感范围授权；默认读取、收集、提方案，额外权限才能直接编辑或移入回收站。用户确认入库、授权、偏好保存和系统设置不交给该 API。

写入核对基础版本、请求 ID 和偏好版本。读写检查引用范围。原始文件按 ID/哈希访问，禁止任意路径和 Shell。原先界面 RPC 的令牌不用于 Agent 身份。

Skill 的源码随仓库维护，可导出 ZIP。应用维护的基线与用户明确保存的偏好补充一起通过 bootstrap 提供；新增偏好共享实体遇冲突阻止 Agent 新写入。导出快照不是自动安装，也不后台修改其他应用。

## 替代方案

不采用公开界面 RPC 或直接访问 SQLite：会绕过范围、审计和版本约束。不新增云网关。不在本轮扩展 MCP，采用可被不同本机 Agent 使用的 HTTP 与无依赖客户端。

## 后果与验证

外部 Agent 自行提供模型、提取工具及费用控制。纯云端 Agent 不能直连本机回环地址；16 MiB 以上原文件目前不支持 Agent 分块传输。独立设备分别授权，所有同步端需升级到识别 agentPreferences 的构建。

自动化覆盖实际本机 HTTP、撤销/到期、跨库/敏感引用、重复提交、并发、方案部分确认、偏好变化、导出及桌面接口。实际外部 Agent 工具环境和真实百度双机另行验收。
