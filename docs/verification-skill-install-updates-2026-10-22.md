## 限制

- 只处理本机明确关联的已有安装，每台电脑及每个安装位置需首次关联；不支持直接写网络共享路径，不扫描或接管未知安装。
- 只更新随本应用提供的 Skill 和已保存偏好，不执行脚本、不改宿主连接/凭证，不新增任意 Skill 安装器。
- 安装文件与宿主已加载上下文分开；未验证各第三方宿主热加载，不能保证无需重载或新会话。
- 按文件原子替换并最后写 manifest，不能保证第三方正在读取整个目录时的事务视图；显式更新提示暂停使用此 Skill，自动更新需用户逐位置开启。
- 物理断电/磁盘硬件故障未实测；测试覆盖注入写失败及持久化中断恢复。外部修改冲突不强行自动覆盖。
- 完整测试使用隔离实例，未改变真实 Agent 安装；已有安装包不包含本轮改动。
