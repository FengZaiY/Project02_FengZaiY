# FengZaiY 0.1.13

日期：2026-10-27。本版在 0.1.12 基础上统一当前产品命名，并保留旧资料与外部调用兼容。

## 本轮变化

- 产品、窗口、MCP 服务/配置统一为 FengZaiY；28 个发现工具使用 FengZaiY_ 前缀，环境变量使用 FENGZAIY_*。
- 内置 Skill 技术名称与目录为 fengzaiy，导出包名为 FengZaiY.zip；包、URI、IPC、媒体协议、标记及阅读偏好更新。
- 旧具名 MCP 请求沿用同一鉴权、权限与幂等入口；旧变量、笔记链接、导图元数据及数据位置继续兼容读取。
- 新旧数据目录同时存在时拒绝自动选择，工作区同时持有两代锁，避免旧程序绕过占用保护。不可变事件、哈希和确定性身份不改写。
- 安装 appId 使用 cn.fengzaiy.desktop，显式固定原安装身份对应 NSIS GUID 7457b9bb-d48d-5e54-9394-6a2683571810；真实跨版本安装体验仍须单独验证。

## 升级要求

新 fengzaiy:// 引用和导图元数据要求 format 8，旧 format 3–7 继续读取；所有参与新内容同步的电脑须统一升级。旧冻结发布计划如含新命名引用会被拒绝，须取消后重新生成。

旧 studyself-organize 目录的已关联安装提示更换名称并暂停自动更新。请导出新包，安装 fengzaiy 目录后重新关联；旧安装的检查、恢复和解除关联保留。系统不扫描或改写外部 Agent 配置。

真实 GitHub 仓库仍为 FengZaiY/Project02_StudySelf；原有用户路径不重命名。秘密、系统管理及用户确认权限边界不变。

## 交付

从新固定提交构建 Windows x64 安装包、更新文件、源码快照及校验清单，仅创建 Release 草稿，未经用户明确确认不公开。实际测试、签名及安装验证范围以本轮交付验证记录为准。
