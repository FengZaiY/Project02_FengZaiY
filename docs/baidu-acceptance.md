# 百度网盘真实双机验收

状态：待人工真实设备验证。自动化测试仅模拟两个独立本地目录间的文件交接。

## 准备

1. 两台 Windows 电脑安装相同版本 StudySelf，分别填写不同设备名称。
2. 两台电脑登录自己的百度网盘官方客户端，确认账号确实可使用双向同步空间，而非只有单向备份。
3. 创建独立的 StudySelf 测试同步目录，不把任何正在运行的 SQLite 数据库放进去。
4. StudySelf 选择该目录，第一台生成配对密钥，在第二台通过独立安全方式填写相同密钥，核对界面配对指纹。
5. 保持网盘客户端与 StudySelf 在需要同步时运行。核对目录排除规则、文件数和大小限制、同步空间配额。
6. 首轮只用无敏感信息的测试笔记。准备一个小图片、一个大于 16 MiB 的测试视频及一个独立备份目录。

## 验收表

| 项目 | 操作 | 必须观察到的结果 | 实测 |
|---|---|---|---|
| 错开上线 A→B | A 保存笔记并生成传输文件，确认官方客户端上传后退出 A，稍后打开 B | B 导入完整笔记；B 生成回执；A 下次上线后看到另一台已接收 | 待验证 |
| 错开上线 B→A | 反向重复 | 内容一致，设备身份不混同 | 待验证 |
| 并发修改 | 两台在各自未收到对方修改时编辑同一笔记，随后同步 | 显示两个版本；没有静默覆盖；人工融合后两端一致 | 待验证 |
| 编辑中到达新版本 | 一台保留未保存编辑，另一台保存并同步 | 保存时提示新版本；可保留独立并发版本，不丢本地编辑 | 待验证 |

## 失败处理

- 如果客户端不支持所需双向同步、重命名/最终文件到达不可预期，暂停该路线，不将其标为正式可用。
- 如果无法自动控制按需下载，沿用“官方客户端下载＋StudySelf 哈希关联”的回退方式。
- 如果任何状态无法从客户端核验，继续显示未核验，不根据文件存在或等待时长推断上传完成。
- 不启用未获授权的替代云服务，不提取网盘 Cookie，不借用体验密钥上线。
- 配对密钥或设备被泄露时，停止同步，备份当前知识库，然后生成新配对组并重新发布记录。
