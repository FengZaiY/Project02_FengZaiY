# StudySelf 0.1.9

日期：2026-10-23。当前为发布准备，正式公开前由用户核对。

## 兼容与授权变化

- 外部 Agent 统一使用本机 `/mcp`；旧 `/v1/rpc` 返回 404。请更新 Skill 和分发客户端脚本，旧 HTTP RPC 脚本不可继续使用。
- 每个有效凭证可访问全部当前及未来知识库，包括敏感资料，并使用现有读取、收集、方案、正式笔记修改、关联及回收工具。旧有效凭证启动时升级此范围，不改变哈希或有效期；请核对已有授权，撤销不再需要的凭证。
- 确认方案入库、永久删除、偏好保存、设备、授权及系统管理仍由用户界面执行，不开放通用 RPC 或系统文件访问。
- 撤销授权事务删除该凭证及对应访问记录、请求回执；启动清理旧撤销残留，知识内容保留。

## 修复

- 已关联且归属匹配的 Skill 安装可预览缺失文件并确认“补全并更新”；自动更新不擅自补全，额外文件和操作前副本保留。
- 未确认同步附件的传输分块缺失时从原件补齐，包含无内容修改时重试；无法补齐则阻止完成。文件生成不代表云端上传成功。
- 存储位置重启共用退出保存保护，复查导入、读取、清理及最后时刻新增操作，数据库与占用锁关闭后再重启。
- 附件预览通过同一文件句柄校验状态、实际大小和 SHA-256；媒体范围读取缓存绑定文件身份、时间、大小与预期哈希，变化后重验。
- 凭证、MCP 配置、Skill 文件和路径复制共用兼容回退；自动复制失败时选中可见内容并提示手动复制，不误报成功。
