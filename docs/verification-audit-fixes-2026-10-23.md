## 修复结果

1. **同步缺块复用**：已知描述与复用依据分开。本机未确认上传的分块消失后，发布会从原件重新生成；无内容修改时重试也能补齐。原件同样缺失则阻止完成。用户确认过的批次和整次发布保留复用依据；其他设备已导入的附件索引可供仅索引设备继承。自身清单回读和旧计划里的 `reusable` 标志不能绕过补齐。沿用分批、暂停、空间检查及原传输格式，不宣称核验了云端上传。
2. **存储重启保护**：目录变更重启复用正常退出握手。检查未保存偏好/标签、进行中导入、清理、原件读取和其他操作，确认时再次核验。数据库及工作区/位置锁关闭后才调用重启；IPC 等待最终结果，不序列化未完成的 Promise。隔离测试在弹窗出现后插入新导入任务，确认重启仍被拒绝。
3. **附件预览完整性**：普通预览与媒体读取共用 `asset-reader.mjs`。验证实际大小、状态、绑定和非链接路径，读取与校验使用同一文件句柄；普通预览验证实际返回字节的 SHA-256，并在异步读取后复查身份。被改写、变大、回收、冲突或链接替换的附件不能冒充正常原件，读取保护在成功/失败后释放。
4. **桌面复制**：凭证、Skill 文件、存储路径和 MCP 配置共用兼容 helper。弹窗内复制的临时选区位于弹窗中，避免页面其他区域被 inert 后误复制旧选区。自动复制失败时选中仍然有效的可见值，并提示 Ctrl+C；凭证仅在用户触发手动回退时显示，关闭弹窗清除。不放宽桌面安全策略。
5. **媒体范围读取**：文件身份、大小、纳秒修改/变更时间和预期哈希共同约束校验缓存，进程内每工作区最多 128 项。重复 Range/HEAD 不再全量读盘；状态改变重新校验，无效 Range 在散列前拒绝，请求取消释放读取保护。
