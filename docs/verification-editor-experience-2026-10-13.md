## 发现与修正

- 浮动工具栏补充浏览器选区更新监听；工具栏点击不抢走编辑器焦点。
- 插入引用后清除的是后续输入链接格式，修复原链接被同时移除的问题。
- 手动快捷菜单在选区移动或继续输入后关闭，避免误用旧插入位置。
- 历史切换记录时校正比较父项；异步历史读取返回前切换笔记则不展示旧请求。
- 初期专项失败包括测试使用错误的备注确认按钮、未等待笔记切换和未将所选内容滚动到视口；改为核验实际完成状态后最终通过。未用放宽产品校验替代修复。
- 桌面首次沙箱执行遇到渲染进程错误，按批准的测试方式在沙箱外使用隔离资料重跑，完整结束并通过。

## 明确边界

- 备注依赖精确引用文本，不是永久段落锚点；原文改变不自动猜测新位置。
- 历史差异为内容块级，非逐字符修订标记；大文档限制二次复杂度，超过阈值退化为完整移除/新增对照。历史 API 仍一次返回记录列表，暂未分页。
- 反向引用展开时扫描当前笔记分支，超大工作区尚未做索引性能验证。
- 代码块提供语言信息、复制和本机显示换行，不含语法着色。浏览器的真实系统剪贴板权限提示及各来源应用（Word/Excel/网页）的全部剪贴板变体未逐个实测；测试使用 HTML/TSV 和图片 ClipboardEvent，桌面另验证实际 File 字节桥接。
- 外部媒体不自动抓取；粘贴不能保留的图片/嵌入内容明确提示。没有承诺完整复制飞书编辑器。
- 本轮未运行安装包构建/安装升级、真实网盘双机、真实外部模型推理及超大规模性能测试；未重跑无改动的独立资料管理/层级/存储专项。原有测试结果不冒充本轮新增实测。
