# 草稿与知识库统一界面验证

日期：2026-10-20。Windows，Node 24.16.0，开发源码。沿用前一轮归档实现，所有交互写入测试使用隔离工作区。

## 本轮实现

- `record-navigation.js` 和 CSS 统一正式笔记列表及草稿列表，提供紧凑行与正文摘要、选中状态、完整名称提示和本机摘要偏好。
- 共用导航显隐控件；搜索、筛选、摘要和导航切换不销毁编辑器。窄窗口返回草稿列表不切换为正式知识体系。
- 草稿新建入口、空状态和标签按钮文案一致；未选库时弹窗选择归属，创建时保留草稿类型。恢复工作区标签时按实际记录类型打开页面。
- 反向引用查询同时查找正式笔记与草稿。保留处理状态、原附件、两条归档路径及原有数据协议。草稿不自动获得正式笔记层级。
- 紧凑行省略摘要后，保存回调改为检测摘要元素并保留标题图标，避免界面回调错误把已完成写入显示为保存失败。
