日期：2026-10-27。本轮仅准备本地版本提交，未推送或生成新安装包。

## 功能范围

- 移除交互阅读切换、页面设计与执行、方案及历史页面预览、专用依赖和 MCP 页面能力。普通正文、图表、媒体、原附件、出处及修改历史保留，内置 Skill 同步调整。
- 旧页面字段先校验再清理；保留版本身份、父版本和草稿确认关联，处理本机缓存、冻结任务及受保护投影。旧加密历史先生成替换后删除中转副本，失败可重试。
- 多电脑同步分为发送与接收，支持窄窗口布局及按需展开配置、空间详情和检查；状态区分文件生成、用户确认上传、记录合并与原件到齐。
- 同步操作局部刷新，保留配置输入、展开状态、焦点和已切换页面的正文；限制重复点击，接收结果与后续检查失败分别报告。
- 增加预览确认“解除本机同步绑定”：事务取消未完成发布并移除本机密钥及目录配置，忙碌或确认过期时拒绝；保留知识、未保存正文、原件、断点、共享文件及设备角色记录。解绑不影响其他电脑，不操控百度客户端，不向 Agent 开放。
