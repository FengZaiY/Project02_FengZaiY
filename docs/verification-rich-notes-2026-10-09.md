## 核实内容

- 六级标题、任务勾选、高亮块、表格增行、公式、彩色贴纸；公式修改及撤销、重开仍可编辑。
- 流程、框架/架构、思维导图、看板、甘特、UML 类/时序/状态、饼/柱/折线共 11 个模板均实际渲染，检查 SVG 文字，不只检查节点存在。
- 画板对象文字、矩形拖动、箭头、撤销/重做、缩放和非空像素；检查桌面与窄窗口截图，缩放窗口后保留可见中心。
- 导入生成的 PNG、含实际画面帧的 WebM；真实加载并播放，媒体 ID 随正文保存。桌面协议也验证了非空图片显示。
- 内部笔记链接跳转、跨标签返回、保存前后全部富内容块数量一致；Markdown 导出保留块 JSON 与内部链接。
- 原始未转义箭头的导入图表可清理、显示；脚本、事件属性、外部图片、危险链接、伪装操作属性和伪装界面 ID 在正文/历史预览中被拒绝。
- Agent 无法借正文链接、嵌入图片或来源 URL 绕过知识库及敏感授权；历史版本、重复保存和撤销授权仍检查。
- 富内容及原始版本哈希经过加密目录传输、独立备份恢复后保留。本地文件路径绑定不随传输或备份导出。
- 媒体读取拒绝未授权请求、错误 Origin、非法/多段范围、篡改和已删除附件；支持 GET/HEAD、合法单段及后缀范围。

早期验证发现并修复了异步显示 DOM 重新解析、箭头触发 XML 清理、插入链接后误清除格式、任务视图标记和图表中文标签问题。最终测试在修复后重跑通过，不沿用早期失败结果冒充完成。

已查看 `artifacts/rich-ui/` 下桌面、1165×892 用户窗口、600×900 窄窗口、画板及图表截图，并检查 `artifacts/desktop/development-window.png`。自动断言页面无横向溢出，正文底部和状态栏实际可达。窄窗口只是 Windows 窗口适配，不表示新增手机端。
