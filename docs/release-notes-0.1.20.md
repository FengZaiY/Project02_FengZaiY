# FengZaiY 0.1.20

2026-11-02

- 减少笔记目录首次加载时的正文读取，只提取导航所需的标题、层级、顺序和分支状态。
- 复用中文标题比较器，减少排序中的重复计算，保留中文及同名排序规则。
- 状态轮询中的旧逻辑清空统计使用现有元数据，文件清理任务状态继续实时读取。
- 补充目录等价、冲突分支、回滚和重开测试，修正树拖动测试的编辑器保留预期与输入时序。
- 校正 README 和状态文档中的 MCP、授权、文件布局及 Skill 更新边界。

同机隔离千条笔记样本中，目录首次读取从 138ms 降至 22ms，轻量状态从 21ms 降至 2ms；样本不代表所有设备的响应保证，全文搜索仍为线性扫描。

本版不改变持久化结构、同步格式、UI 协议、权限或保存冲突规则。升级不等于自动完成旧工作区迁移。

仅创建 Release 草稿，正式公开前由用户核对。安装包未签名；真实安装、卸载、跨版本升级及双机联调未验证。本轮固定提交的实际构建和测试结果在交付后另行记录。
