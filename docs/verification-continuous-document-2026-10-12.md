# 连续文档编辑验证

日期：2026-10-12。环境：Windows、Node 24.16.0、Playwright Chromium/Edge 回退及开发 Electron。测试全部使用 `artifacts` 下独立工作区。未生成安装包。

## 改动与兼容

- 移除运行时文字布局节点及其长按、缩放操作区。表格、高亮块和拖入的普通文件链接直接加入正文。
- 清理 HTML 后递归展开旧文字容器，保留子内容及空段落；含普通正文的旧横排按阅读顺序展开，纯媒体横排保留。
- 载入、HTML 粘贴、只读历史沿用同一入口。仅打开不保存转换；实际编辑保存连续结构，旧数据库事件及原件不重写。
- 图片、视频、公式、图表和画板的源数据、稳定引用与媒体尺寸继续保留。后台旧格式校验和同步保持兼容。
- 项目约定、架构、Skill 基线与 API 说明同步更新；应用内补充偏好不被覆盖。
