# StudySelf 0.1.7

状态：源码版本与发布说明准备完成，用户已安排合并提交功能与版本，尚未打包或创建 Release。

## 本版更新

- 系统设置的本地存储新增同步接收目录检查，分页查看等待续传、正在读取、原件绑定、本机链接、待校验清理及未知文件状态，并可重试现有目录整理。
- 原件目录整理与永久删除收尾支持移除已无内容、绑定、续传登记或本机链接的空接收目录。
- 原件旧副本清理增加本机文件链接保护，避免清理仍被本机链接引用的副本。
- 检查与整理保留未保存的整理偏好，不重建偏好编辑区；新接口只向受信任界面开放。

## 使用与兼容

接收目录为本机 `received-objects`，状态是本机快照，不代表云端上传、下载或全工作区同步已完成。状态检查不读取原件正文、不校验整份大文件，不访问外部目录。

清理仅非递归移除符合保护条件的空目录。绑定、续传登记、本机链接、未知文件和异常路径保留；非空托管旧副本继续经过原有引用及哈希校验，已有永久删除任务在相应清理入口处理。本版不提供任意残留文件清空。

不修改同步格式、密钥或历史校验值，沿用 0.1.6 的 format 5 设备管理兼容要求。**本版未修复历史 checksum 问题**，接收目录整理不能作为历史校验和修复手段。
