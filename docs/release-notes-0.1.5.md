# StudySelf 0.1.5

状态：源码版本与发布说明准备完成，用户已安排合并提交功能与版本修改，尚未打包或创建 Release。

## 本版更新

- 新增交互式笔记：在完整可编辑、可搜索正文之外，支持交互图表、参数计算、视图切换及逐步演示页面。
- 外部 Agent 可在整理方案中设计页面，用户预览后按笔记部分确认或局部重做；正式设计不由 Agent 直接发布。
- 正文与交互页面共同保存修改历史、同步和恢复；正文变化后保留旧页面并提示待更新，阅读与编辑切换保留编辑状态和原附件预览。
- 页面使用本地图表、公式、流程图和稳定附件引用，在隔离环境运行；不提供任意网络、系统文件或凭证访问。
- 外部 Agent 新增官方 MCP SDK 的本机 Streamable HTTP 接入、按权限发现的具名工具及连接配置复制；既有 HTTP 接口继续兼容。
- MCP 沿用知识库授权、敏感内容保护、撤销、请求幂等、基础版本、整理偏好版本及访问审计。

## 使用与兼容

同步使用的电脑应共同更新，以完整保留交互页面及引用保护。旧客户端省略页面字段时保留已有设计，明确传入 null 才表示移除；旧记录和历史哈希不改写。

Markdown/PDF 导出保留正文，不包含可运行交互；JSON 保留完整页面源定义。页面不是任意网页或 npm 应用运行环境，页面引用的重复附件目前需先调整设计引用再合并。

MCP 服务默认关闭，只在本机监听，需用户单独授权。提供无会话 Streamable HTTP，不支持 stdio、旧 SSE、OAuth 或云端直连。连接配置不含真实凭证，也不会自动修改外部客户端设置。标准 SDK 联调不代表 Codex、WorkBuddy、豆包等产品已逐一实测。
