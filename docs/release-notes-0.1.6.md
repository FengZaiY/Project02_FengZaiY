# StudySelf 0.1.6

状态：源码版本与发布说明准备完成，用户已安排合并提交本轮功能与版本，尚未打包或创建 Release。

## 本版更新

- 新增主力机设备管理：当前唯一主力机可统一修改设备名称、停用/恢复其他设备，并发起或取消主力机转移。
- 主力机转移采用两步确认：目标电脑拉取后明确确认，并校验本机已接收范围的原件；生效前原主力机继续保留资料。设备名称、启停及角色并发冲突保留并明确处理。
- 系统设置的 SKILL 管理新增“安装更新”：通过目录选择关联已有 studyself-organize 安装，运行期间每分钟检查并提醒，也可逐位置开启自动更新。
- Skill 更新包含内置文件和已保存整理偏好；手工修改或路径异常时暂停自动覆盖。显式更新提供预览和上一份文件恢复，失败及中断通过持久化日志恢复；解除关联保留安装文件。
- 普通笔记与草稿也显示交互阅读入口，无页面时明确显示尚未生成。新增“复制设计请求”，携带记录标识、当前版本及知识库范围，交给外部 Agent 提交待确认设计；不复制正文、不调用模型或直接生成页面。

## 使用与兼容

包含设备管理记录的同步清单使用 format 5，仍兼容读取旧格式；所有参与同步的电脑须共同升级至支持该格式的版本。停用不删除知识、历史、原件或同步包，管理状态通过现有发布/拉取传播，不是共享密钥撤销、即时远程控制或对旧客户端的强制隔离。已知被停用的电脑只接收管理状态以获取恢复通知。

Skill 安装位置需每台电脑分别首次关联，不扫描其他 Agent、不修改连接和凭证，也不更新未关联副本。关联、摘要和恢复副本仅存本机。安装文件已更新不代表运行中的 Agent 已重新加载，可能仍需宿主重载或新会话。仅处理固定内置文件与已保存偏好，额外文件保留。

复制设计请求前检查编辑保存状态，设计仍需经整理方案预览确认；不增加内置 AI 或后台推理。
