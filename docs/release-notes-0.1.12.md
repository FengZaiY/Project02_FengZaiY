# FengZai·Y 0.1.12

2026-10-27。由 StudySelf 升级为五板块个人管理系统，保留旧安装身份、工作区及 studyself 协议兼容。

## 新增与修复

- 五板块：知识与笔记、资料管理、账号与订阅、财务管理、任务管理；个人项目和任务使用独立范围。
- 独立加密密码库、恢复密钥、加密秘密草稿、自动锁定及受保护剪贴板；密码秘密不进入 MCP、搜索、普通导出或日志。
- 最小货币单位整数记账、手工汇率、转账/退款、预算与报表、CSV 映射预览及事务导入、订阅确认付款。
- 资料集合、跨板块引用、集中原件与可恢复迁移；用户和 Agent 修改形成可受保护整批撤回的修改记录。
- MCP 扩展非秘密个人业务，内置 Skill 同步更新；不开放密码秘密、系统管理和用户确认操作。
- 修复付款/CSV 撤回后重做、账户期初日期、业务保存竞态、密码提交输入保护及回收详情恢复入口。
- 启动协议检查与可重试错误页，避免旧服务和新界面混用导致白屏；修复品牌中文字符影响桌面媒体请求。
- 包含本机 0.1.11 的交互阅读退役、同步操作体验优化及显式解除本机同步绑定；保留普通正文、原件及历史。
