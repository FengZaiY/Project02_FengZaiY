- 已安装 Skill 是副本；运行时获取最新版，不后台自动覆盖其他应用目录。应用内偏好只有用户明确保存才会持久化，不从聊天或资料里自动推断。
- 新 `agentPreferences` 实体需要两台电脑都升级到支持该实体的源码构建。旧备份和原内容无需重建。
- 真实目标外部 Agent 的环境变量/工具接入仍需用户授权后实用验证；本轮验证使用同一 Skill 客户端操作隔离资料。
- Excel/完整专题导出、长视频外部接口、大规模长期历史保留策略仍待后续需求，不冒充已实现。
- 实际双机部署联调按需记录，重点排查本系统接收、恢复及状态呈现，不重新验证百度产品能力，不作为开发前置条件。
- 安装、卸载、跨版本升级和签名在独立打包任务验证；本轮不生成安装包。

需求或协议变化须同步更新 Skill、项目约定与测试；验证结果保存命令、环境和未验证范围。不能仅靠改文档把计划标为已完成。
