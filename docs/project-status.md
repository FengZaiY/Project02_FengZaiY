## 当前：草稿归档与整理结果

“收集与草稿”支持两条路径：“归档为正式笔记”选择知识库和上级笔记后保存正文、附件、出处、标签及敏感标记，保留来源草稿与历史；“整理后归档”查看外部 Agent 提交的关联方案，用户可部分确认并打开整理结果。直接归档同一草稿版本可重试，跨设备并发保留冲突，不重复静默生成多份结果。

处理状态按当前草稿版本与已确认结果派生为待处理、部分处理、已处理。列表默认显示待处理和部分处理，已处理仍可筛选或搜索；来源再次修改重新待处理，旧结果仍可追溯。仅做部分提取的方案即使全部确认仍为部分处理；完整整理须由方案明确声明覆盖完整，并由用户确认全部相关项。系统不能独立验证语义上的完整性。已回收、缺失或冲突结果不算完成。
