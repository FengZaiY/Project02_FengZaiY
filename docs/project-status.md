## 当前：文件拖放、布局与自动保存

交互更新：插入内容已移除外框、底部工具条与编排按钮。直接长按素材一秒后显示悬浮预览，拖到上下/左右落点重排或并排；四条边和四个角均可缩放，图片与视频保持比例。小字标题位于实际素材内部下方，编辑/移除按钮在悬停或聚焦时显示于内部右上方。Escape、取消指针或失焦撤回未提交的手势，短按和视频底部控件不启动编排。原布局格式和已有笔记不迁移、不重写。

正式笔记支持拖入本地文件：图片/视频使用稳定附件引用显示，其他文件插入内部附件链接；部分失败时保留成功导入项。内容块支持拖动重排、并排、纵排、调整尺寸和对齐，默认自适应编辑区。普通附件、表格和高亮块使用可编辑布局容器；尺寸与排列随正文、历史、导出和同步保留。

停止编辑约 1.5 秒后自动保存，手动保存继续可用并显示保存状态。按笔记串行写入，切换标签仍保存原笔记，保存期间的新输入保留并继续保存；失败和基础版本冲突暂停自动重试，草稿保留，不自动创建并发分支。

此前拖放与自动保存实现已通过 122 项核心测试、构建、通用/知识库/Agent/存储/富内容/编辑交互界面及开发桌面回归；详见 [拖放布局与自动保存验证](verification-editor-interactions-2026-10-10.md)。本次直接手势调整的独立结果见 [纯内容与直接手势验证](verification-direct-content-gestures-2026-10-10.md)，未将之前的全量结果作为本轮结果。浏览器单文件上限 128 MiB；不扫描文件夹，不支持页面任意坐标的悬浮排版。其他电脑应更新后再编辑新布局。

上一轮交付时只读确认 13895 仍指向原工作区，原知识库、笔记及三项附件存在。原页面当时有未保存的媒体编辑，所以未重启服务、未刷新页面、未替用户保存。服务端布局校验仍待按原启动参数重启后生效。本次手势调整再次只读核对入口，原知识库与笔记存在，用户新增附件保留，未更换工作区或原服务进程。新静态界面已构建，保存当前编辑后刷新原地址可加载；隔离测试没有写入原资料。

用户取消运行时 Git 版本管理和本地独立备份。Service 使用 v3 `CurrentSync`，笔记保存自动保留修改记录，仍可逐条查看、恢复和处理冲突；整套资料的云端文件历史交给百度同步空间。界面不再提供 Git 提交、整库版本历史或独立备份，旧仓库/备份文件未删除。

发布前冻结当前已保存内容，显示空间预估、可用空间、保留空间和批次上限。发布支持暂停、继续、取消及批次上传确认；目录空间不足会保留进度。大文件接收保留已 flush 的分块与检查点，重启复核前缀后继续，不需要重新获取有效前缀。所有已下载的各设备最新清单可一次拉取，新电脑不需要共享提交或以前的 Git 包。私密配置仍只在本机。

## 边界与待验证

完整资料同步：不永久排除大视频/文档；所有电脑需更新到 v3，旧电脑先发布一次最新内容后，新电脑才能无 Git 拉取。主力机文件哈希回执已实现；同步空间历史不自动删除。仅有外部链接或本机路径绑定、尚未导入的文件不自动上传；正文、文件完整度、用户上传确认分别展示。旧协议验证记录保留，不当作新协议实测。

系统根目录与知识库文件夹：新建知识库建立直接子目录，新导入附件按知识库存放；笔记/历史仍由根目录数据库统一管理，旧附件不强制移动。名称冲突安全避让；改名不自动重命名目录，删除恢复不物理删除目录。目录映射只在本机，Agent 不获知路径。选择新根目录不会静默清空当前资料；空目录走确认迁移，已有工作区走确认切换。专项结果见 [根目录与知识库文件夹验证](verification-workspace-root-2026-10-09.md)。

本地存储设置已接入桌面与预览。桌面与 Windows 预览均提供系统文件夹选择，取消不会变更路径；桌面另有重启入口，预览需用相同启动参数重启服务，刷新网页不执行迁移。已有工作区丢失或损坏时不会静默创建空库。迁移保留历史、附件、本机授权/密钥及阅读位置，拒绝非空目标、目录重叠、符号链接和新版本实例占用；旧版本需主动关闭。预览和桌面凭据环境不同，不能直接互开；当前跨环境内容转移使用 v3 同步并分别配置密钥。历史验证结果见 [本地存储验证](verification-local-storage-2026-10-09.md)。

目录选择改造：根目录、迁移和打开已有工作区先弹出文件夹窗口，再检查和确认；同步使用同一选择器，独立备份及其恢复入口现已取消。历史新增鉴权、取消、失败恢复、重复调用与关闭清理回归通过，原预览根目录、知识库标识/版本和资料数量保持不变。原生窗口进程启动/关闭已验证；原生外观与真实按钮点击尚未核对，详见 [目录选择验证](verification-directory-picker-2026-10-09.md)。
