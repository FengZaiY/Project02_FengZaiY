# StudySelf 0.1.4

状态：本地版本提交，未推送、未打包、未创建标签或 Release。

## 本版更新

- 桌面退出前检查所有笔记和草稿标签的真实保存状态，提供继续使用、查看同步和保存后退出。
- 保存失败、版本冲突、未保存整理偏好、输入法编辑、其他编辑弹窗或正在进行的操作会保留窗口；保存重试不自动创建并发分支。
- 修复桌面通信跨隔离桥接后丢失冲突错误类型的问题，保留明确的冲突处理状态。
- 回收站和系统设置显示全工作区旧版逻辑清空残留及历史数量，支持单独预览确认清理，普通回收内容保留。
- 系统设置新增废弃空知识库目录检查，仅经确认清理归属明确、无历史和引用的目录或失效登记；仍在使用的空知识库、额外文件和未知归属保留。

## 使用与兼容

退出检查用于正常关闭 Windows 桌面窗口，不承诺系统强杀、断电或注销时完成保存；浏览器预览不提供原生桌面退出流程。

退出不会自动发布同步内容、确认百度上传或安装更新。保存冲突须先回到对应笔记处理。

旧版残留永久清理会删除其正文历史及不再共用的托管附件，无法通过应用历史恢复，须在界面核对范围后确认。空目录清理不递归删除，外部源文件和额外文件保留。

沿用 0.1.3 的永久删除同步机制，各同步电脑应共同升级；不承诺删除百度历史、回收站及外部副本。
