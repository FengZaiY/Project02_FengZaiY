# 废弃目录检查修复

日期：2026-10-28。用户反馈“检查废弃空目录”未看到已删除的“测试”知识库目录。

## 定位

通过只读连接及实际预览函数核对：正式根目录保留了“测试”的目录映射，目录内仅旧版归属标识；知识库有永久删除凭据，实体修改版本为0。唯一残余引用是 changeBatch.entries 的实体标识。原扫描泛化匹配整个 JSON，将该标识误判为需要目录的内容历史。此前回复称可直接清理不准确。

开发预览使用独立根目录，其中“测试”仍是有效知识库，不能把该预览的结果当作正式根目录结果，也没有切换或合并两个工作区。

## 修复

只在存在永久删除凭据、且批次引用的 before/after 版本均已不存在时，从本次目录依赖判断中忽略该条批次标识。原批次、历史、删除凭据均不改变。真实记录、无法证明已删除的标识、未完成同步、工作标签、绑定和额外文件继续阻止清理。确认令牌包含根目录及当前预览，实际删除仍须用户确认、重验且非递归执行。

预览返回实际根目录与条目完整路径，弹窗始终显示“可清理目录”和有内容时的“保留目录”，零候选明确提示；不把保留项隐藏在可清理项中。
