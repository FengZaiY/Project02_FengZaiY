# 项目文档索引

## 阅读入口

- [项目说明](../README.md)：如何运行、已实现能力和限制。
- [项目级 AGENTS](../AGENTS.md)：Codex 入口、长期规则、模块地图和维护协议。
- [开发指南](../CONTRIBUTING.md)：环境、命令、测试矩阵和交付。
- [当前状态](project-status.md)：实际能力、待验证项和下一阶段工作。

## 设计与验收

- [架构说明](architecture.md)：修改历史、当前内容同步、原件断点与权限；退役格式单独标注。
- [验证记录](verification.md)：带日期的实际测试结果。
- [同步验收与可选双机联调](baidu-acceptance.md)：StudySelf 自身的版本、完整性与恢复要求，以及按需进行的部署联调。
- [计划目录](plans/README.md)：跨模块和多阶段任务。
- [决策目录](decisions/README.md)：重大方案及其边界。

测试生成的日志、截图和性能数据位于被 Git 忽略的 `artifacts/`；需要长期保留的结论以脱敏文字写入验证文档，不把个人资料或整个测试工作区加入版本控制。
