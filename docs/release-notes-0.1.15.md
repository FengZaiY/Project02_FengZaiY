# FengZaiY 0.1.15

## 本轮变化

- 资料以分类、主题为主浏览；用途集合折叠展示，保留原有集合身份及引用，不搬移原件。
- 系统设置统一更换工作区入口，继续先检查、确认，再重启生效。
- 存储维护先扫描，分项展示已核验可释放空间、旧副本、废弃空目录与异常。清理仍逐项预览确认；部分失败明确显示未完成，旧版迁移收进高级维护。
- 仅为待处理或失败任务提供重试入口，完成任务不重复显示重试。
- 修复已永久删除知识库仅剩修改批次标识时，废弃空目录被错误保留的问题。原批次不改写，缺少删除凭据或仍有内容历史时继续保护；预览显示实际工作区与完整目录路径。
- 初次启动和再次启动时显式显示桌面窗口，必要时还原后聚焦，避免进程存在而窗口不可见。

## 兼容与边界

沿用0.1.14的format 9与内部数据库布局，所有同步电脑应使用兼容新版。迁移后的内部布局不能由旧安装版打开。用途集合只改展示，不更改materialCollection协议或原件路径。

本次发布不执行正式资料清理、工作区迁移或实际整理方案确认。清理仍须本机确认，未知文件与受保护引用继续保留。安装包签名及真实安装、卸载、跨版本升级的状态以本次交付报告为准。

Release仅准备草稿，公开前由用户明确确认。测试与附件来源单独记录，不沿用上次发布结果。
