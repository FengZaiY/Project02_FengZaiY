# StudySelf 0.1.2

Windows x64 版本，发布日期待用户核对后确定。

## 本版更新

- 系统设置新增在线升级：检查更新、查看说明、下载、稍后处理及确认重启安装。启动检查只提示，普通退出不会自动安装。
- 草稿支持直接归档为正式笔记，以及按外部 Agent 整理结果分批确认；保留草稿、正文、附件和出处，处理状态随来源版本变化。
- 系统设置集中管理内置 StudySelf Skill、整理偏好、偏好历史及带版本清单的导出。
- 知识体系支持笔记分支拖动、同级前后排序及后台正文和原件目录维护。
- 正文支持连续编辑、可视化思维导图、富媒体缩放与行间/横向排列；原附件支持关联管理、拖入正文及关闭预览。
- 资料管理支持本机目录、真实图片/视频缩略图、重复资料复用与预览合并；DOCX 支持本机隔离阅读预览。

## 安装与兼容

- 下载 `StudySelf-0.1.2-Setup.exe`。已安装旧版本且没有升级入口时，须先手动安装本版。
- 多电脑同步的所有电脑均应升级，再编辑或同步新增结构、排序、草稿关联和回收站终止记录。
- 保留既有知识库、修改历史、原件和旧格式兼容；不要求删除数据库重建。
- 当前未配置 Windows 代码签名，安装包为未签名版本，Windows 可能提示未知发布者。
- DOCX 为阅读预览，不保证 Word 原始分页；PDF 内嵌预览仍有已知间歇空白问题，原文件保留。
