# 回收站永久删除验证

日期：2026-10-20。环境：Windows、Node 24.16.0、项目既有 Electron 与 Playwright。删除、迁移和同步测试均使用隔离目录，未清空用户正式回收站或清理正式旧工作区。

## 实现范围

- 确认清空后事务删除正文与正文历史，保留不含标题、正文和路径的删除凭据。生成投影和不再共用的托管原件通过持久化清理任务逐文件校验后删除；数据库 checkpoint/VACUUM 单独记录结果，可重试。
- 当前或历史引用、冲突、未保存编辑、正在读取的原件及外部修改均受保护。外部导入源和未登记的额外文件不删除。预览包含文件清单，目录维护改变预览后必须重新确认。
- 同步使用带删除凭据的 v4 清单及独立加密凭据；混合历史先生成保留内容和替换索引，随后删除旧对象。重复接收幂等，未知并发版本阻止导入，保留源端修改。仅取消含被删正文的冻结发布任务，重复删除不取消无关发布。
- 旧版仅逻辑清空的隐藏内容可以再次预览确认；后台通过持久化知识库目录映射核验旧投影归属。迁移旧副本单独确认，核验身份、修改记录、删除凭据、待处理记录及未保存编辑；逐文件清理，保留额外文件。

## 限制与未验证范围

- 未执行用户真实永久删除、真实百度上传/删除、双机部署、安装包构建或发布。已安装/已有草稿的 0.1.2 安装包不包含本轮源码改动。
- 同步电脑必须一起更新。百度云端历史版本和回收站由用户通过客户端另行清理；不会把本地传输副本删除宣称为所有云端副本擦除。
- 退役 Git 仓库、旧独立备份和用户自行导出的副本不自动改写或删除；检测到登记的旧归档时显示提示。无法枚举用户所有外部副本。
- 永久删除是应用层文件删除与数据库压缩，不承诺磁盘取证意义的安全擦除。外部修改、占用、磁盘异常和缺失同步对象可能留下待处理项，需根据原因处理后重试。
- 沙箱内桌面异常与测试启动同时出现，正常桌面重跑通过；异常底层原因未完全定位，不能据此断言已安装应用没有其他问题。
