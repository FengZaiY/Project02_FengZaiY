## 数据与权限

- 本地写入校验同库上级、16 层上限、循环、过期编辑、历史恢复和有子项时的删除保护。
- 提案支持父子项乱序、只确认父项、子项缺少父项时拒绝、整体事务回滚、局部修改和重复请求幂等。
- 授权检查覆盖真实上级、敏感祖先、同批新父级、私有库、目标版本变化和正文内引用；不向 Agent 开放文件系统或确认入库。
- 两个独立数据库转换同一批旧 folder 内容后可合并，不重复创建概览笔记或冲突分支；原事件逐条一致，用户后续调整不会被重新转换覆盖。旧待确认归属也转换为笔记父级。
- v3 隔离传输保留层级与未确认提案，双端并发形成的循环可见且不丢内容。
- 本地目录以知识库为根，唯一引用的原件按笔记组织，多笔记引用使用共享资料位置；原件迁移失败、被手改文件和外部来源均保护。
- 新托管原件释放仍要求当前主力回执、无未发布修改、无使用中/指定保留引用；释放后标记待维护，重新下载校验后可恢复。
