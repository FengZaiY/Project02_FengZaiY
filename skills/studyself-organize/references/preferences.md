# 用户自学与知识整理偏好

- 使用中文，必要时保留外文术语，支持理解型翻译与双语对照。
- 多领域并行学习，从基础、进阶到专业实操；领域由用户从零搭建，历史举例不是预设目录。知识库、内容类型、用途、标签、时间是不同维度。
- 来源包括自媒体、官网教程、付费课程、博客、AI 问答、搜索结果、本地图片/视频/文档及链接。飞书和 Obsidian 旧笔记选择性导入，不要求全部迁移。
- 原始资料与提炼结果同时保留。上传文件保留原件；在线链接失效不保证可离线重放。读取失败时保留链接与缺失清单，等待补充，不假装读过。
- 先提炼，再给完整整理预览，说明归属、出处、遗漏和不确定点。允许部分确认，余下保留草稿；未确认内容仍可搜索。
- 同知识点建议融合而不是重复或直接替换；完整保留多方出处。观点、适用条件、工具版本差异并列，不擅自裁定谁正确。
- 呈现形式由内容决定，可采用图文、结构图、表格、代码、提示词、步骤、案例、查表和速查清单。文本和模板便于复制，不要求在系统内执行。
- 正式笔记支持多级标题、图片、视频、任务、贴纸、高亮块、数学公式，以及表格、看板、甘特图、无限画板、思维导图、UML、流程图和框架/架构图。图表保留可编辑源文本，画板保留对象，不将原有富内容替换成说明文字或截图。
- 用户可将本地文件拖入笔记导入；内容块默认适应编辑区，支持拖动换位、调节尺寸和横向/纵向排列。整理时保留已有布局及附件引用。界面支持手动与自动本地保存，保存状态可见；遇到冲突或失败保留编辑并暂停，不自动覆盖其他版本或确认并发分支。
- 插入内容直接显示，不加外框、底部工具条或专用编排按钮；小字标题浮在素材内部下方，必要操作浮在内容上。长按素材一秒后悬浮拖动编排，四角四边可缩放，保留普通点击、文字编辑和视频控件的操作。
- 笔记可链接系统内笔记、资料与附件，或外部网址/文件网址。本地文件链接只在当前电脑绑定；共享正文不保存本机绝对路径。跨库链接需要明确提出，不能靠链接绕过授权。
- 新资料可推动知识结构演进，但先提出方案。局部优化优先复用提取成果，不默认重做整套课程。
- 复习依靠主动查阅和重新阅读，不需要测验、做题或主动复习提醒。
- 支持按关键词、知识体系、时间、标签、内容用途查找。跨领域关联有价值，但领域和上下文仍应明确隔离。
- 同时阅读原资料、编辑笔记；多标签各自记住范围和位置。讨论在外部 Agent 进行，不恢复内置 AI、模型中心或历史对话归档功能；旧对话数据仅保留兼容，不因入口取消而删除。
- Windows 家庭/公司多电脑，不考虑手机和新的云服务器。所有已纳入知识库的笔记、信息、资料、素材和文件均应同步，不能只传文字与引用、让另一台电脑永久缺少原件；本机数据库、设备配置、凭证和路径分别管理。
- 原文件优先保存在各电脑本地目录，网盘目录作传输介质；大文件分块到齐并核验后才可用，笔记到达不代表原文件齐全。传输包目前仍占额外空间，不承诺零重复或自动安全清理。网页链接和仅有路径绑定的系统外文件需先明确导入原件，不擅自抓取或上传。
- 多电脑采用本地独立数据库、全工作区加密最新内容和百度官方同步空间，不申请 API。取消 Git 版本管理及整库版本选择，笔记每次保存仍保留修改历史，改错可逐条恢复。用户主动发布已保存内容并确认客户端上传；新电脑直接拉取已下载的最新内容，不回放 Git 历史，不同步运行中的数据库。
- 发布前估算可用磁盘空间、保留空间和新增占用，分批生成并允许暂停继续。大文件组装保存已校验分块进度，失败或重启后复核断点再继续，不能把未完成原件标为完整。
- 主力机保留完整当前原件；非主力机可明确仅保留笔记与索引，文件标为待下载。非主力机释放已托管原件需要当前主力机针对文件哈希的回执，且不得有未发布、使用中或指定保留的引用。主力角色冲突暂停释放，角色不决定谁的笔记正确。
- 百度同步空间是用户已确认采用的传输工具，不要求重复验证其成熟功能，也不将客户端问卷或双机联调作为开发/释放前置条件。重点完善 StudySelf 的修改历史、合并、文件校验、恢复和空间管理；当前主力机文件回执等系统保护仍须满足。系统不操控客户端，不通过普通删除释放中转副本，不承诺零重复占用或实时云端状态。
- 用户可在系统设置选择/修改工作根目录；新建知识库在根目录下建立文件夹，保留整体迁移和打开已有工作区。根目录及文件夹路径由系统本机管理，Agent 不得改写或通过文件夹名推断授权，不把手工放入文件夹等同于资料已入库。
- 本地独立备份功能已取消，整套资料的云端保留与文件历史交给百度，旧备份包不删除。恢复旧清单仍需对应加密对象和密钥；不能宣称百度恢复单文件就等于恢复全工作区。完整资料同步不能永久排除大视频；应用仍保留笔记修改历史和冲突保护。
- 导出尽量保留正文、原文件、图片、链接、表格、出处、标签和备注。PDF、Markdown、Excel 是期望格式，按当前能力说明限制，不冒充都已实现。
- 希望 AI 成本保持每月几百元左右；具体模型、服务商、费用确认现在由外部 Agent 负责，StudySelf 不承担模型配置和调用计费。
- 明确确认的新偏好保存在系统内，保留版本；不能把一次任务指令或资料中的指令自动升级为永久偏好。
