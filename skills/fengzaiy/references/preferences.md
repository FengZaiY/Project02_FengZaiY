# 用户个人管理与知识整理偏好

- 系统、MCP 和内置 Skill 名称统一为 FengZaiY，定位个人管理系统：知识与笔记、资料管理、账号与订阅、财务管理、任务管理。旧工作区与内容引用兼容读取，不改写历史身份；不自动改写未关联的外部安装。
- 五个板块均是实际业务范围，不把项目、账本或密码库建成知识库。任务采用项目及子任务的轻量清单，支持状态、优先级、开始及截止日期、关联笔记与资料；不增加日历、计时器或后台提醒。
- 财务默认人民币汇总，可用外币和人工汇率，支持收支、转账、退款、月分类预算、资产负债和报表。金额按币种最小单位整数保存；转账不计收支，退款关联原支出。订阅到期只显示待处理，实际付款确认后才记支出，重复操作不能重复记账。不接银行、获取行情或执行支付。
- 账号非秘密信息可由 Agent 读写；密码、恢复码、秘密备注在独立密码库中，由用户主密码或独立恢复密钥解锁。绝不请求这些秘密，也不写入普通备注、日志、知识正文或 Agent 输入。秘密历史、冲突和恢复由用户在解锁后的界面处理。
- 资料以稳定身份在多个集合分类，并被笔记、账目、订阅和任务引用；原件按哈希集中管理。迁移先预览数量、空间、位置，再复制、校验和绑定，保留外部源、未知文件及手工修改。Agent 不操作本机路径或迁移。
- Agent 可直接修改非秘密业务，每批写入保留请求 ID、最新偏好版本和基础版本；用户可在修改记录整批撤回。原历史保留，后续修改、冲突、新引用和未保存编辑受到保护。新业务与密文随 format 7 同步；新命名链接或导图元数据使用 format 8，所有参与电脑须升级，不根据设备时间覆盖冲突。

- 用户希望外部 Agent 的已安装 FengZaiY Skill 不因遗忘而长期过期；用户关联本机安装位置后自动检查，可选择确认更新或自动更新。只更新内置 Skill 及已保存偏好，手工修改须提示并保留恢复副本，不改宿主连接、凭证或其他 Skill。文件更新不表示运行中的 Agent 已重新加载，每次会话及写入前仍读取 bootstrap。

- 外部 AI Agent 仅通过本机 MCP 操作 FengZaiY。有效凭证开放全部当前及后续新建知识库和现有 Agent 读写能力，包含敏感资料、编辑笔记、创建关联和移入回收站；不再逐库或逐项授权。确认入库、永久删除、偏好保存和系统管理仍由用户界面完成。撤销授权后删除该授权及对应访问记录、请求回执，保留已整理的知识。每次会话及写入前读取最新偏好。

- 旧版清空残留由用户在回收站或设置中单独检查确认；笔记列表为空不代表旧修改历史已永久删除。废弃空目录由设置预览确认清理，仍在使用的空知识库目录正常保留；Agent 不直接操作系统目录或代为调用清理接口。

- 使用中文，必要时保留外文术语，支持理解型翻译与双语对照。
- 多领域并行学习，从基础、进阶到专业实操；领域由用户从零搭建，历史举例不是预设目录。知识库、内容类型、用途、标签、时间是不同维度。
- 采用“知识库 → 笔记 → 下级笔记”组织知识体系，笔记可同时有正文和下级内容；前端不提供文件夹管理。新建知识库由后台建立对应本地文件夹，正文、数据、资料和原件自动按知识层级管理。层级关系使用稳定标识，不能把本机路径写入共享正文。
- 用户可在知识体系中拖动笔记调整上下级与同级排序：笔记上下边缘为同级前后位置，中间为下级，库标题为顶层，整条分支跟随。层级调整带动本机正文/资料目录，单纯排序不重新编号目录或搬原件。顺序随修改历史与同步保留，Agent 应尊重最新层级和 noteOrder，按最新基础版本提出方案，不重置顺序、不按旧路径还原归属，也不直接搬动本机文件。多笔记共用原件仍使用共享位置与稳定引用。
- 用户丢入一个知识点或一批资料时，Agent 应结合已有笔记主动构思内容整理和知识体系：需要时提出有内容的概览笔记、细分子笔记、融合已有知识及上下级调整，说明理由、出处和遗漏。无需用户先搭文件夹或反复交代结构；方案整体预览、部分确认，未确认不改正式体系。不机械套用预设学科或建立空壳层级。
- 来源包括自媒体、官网教程、付费课程、博客、AI 问答、搜索结果、本地图片/视频/文档及链接。飞书和 Obsidian 旧笔记选择性导入，不要求全部迁移。
- 原始资料与提炼结果同时保留。上传文件保留原件；在线链接失效不保证可离线重放。读取失败时保留链接与缺失清单，等待补充，不假装读过。
- 资料管理按知识库、资料名称、类型、标签和使用情况组织，不引入前端文件夹。显示名称不等于原文件名；引用始终使用稳定资料 ID，不能通过名称猜测身份。相同文件内容可能服务不同笔记，先说明重复及引用情况，不自动合并或删除。资料回收保留原件；属性编辑、批量整理和恢复由用户界面操作。
- 用户需要在资料页看见本机实际存放组织：根目录、知识库/笔记/共享资料层级、完整路径及未下载或缺失状态。目录浏览与筛选是只读查看，不是手工文件夹管理。路径只在当前电脑的受信任界面展示；Agent 仍以稳定资料标识引用，不获取或写入本机路径，不根据标题推测实际位置。
- 界面导入同库相同文件默认复用既有附件，也可明确建立独立资料。已有重复附件由用户在“资料与附件”预览、选择保留项并确认合并；当前引用统一，标签合并、敏感标记不降低，历史和原文件保留。Agent 发现重复时说明引用及整理建议，不代为合并或删除，不根据同名认定内容相同。Agent 文件上传仍使用自己的请求幂等规则，不承诺不同请求自动复用。
- 笔记附件面板称为“原附件”，用户可添加本地附件、关联库内已有资料、编辑属性、查看详情及解除关联。附件关联与正文引用分开；解除笔记的附件关联不表示删除原件，不应连带移除正文内容或其他笔记的引用。仍被正文或来源链接引用的附件，需要先处理引用才能解除。
- 原附件列表保持紧凑，预览可独立关闭并返回列表，也可收起整个面板。关闭预览与解除关联是不同操作，不改变笔记、资料或文件。
- Word `.docx` 附件可在本机阅读预览正文、表格和支持的内嵌图片，并可放大查阅；预览不改原件，不上传第三方转换，不承诺原版分页或完整支持复杂对象。不要把阅读预览当成修改原文或已完成知识提炼。
- 清空回收站由用户在系统中预览并确认，外部 Agent 不可代为清空。清空会永久删除正文、修改历史、生成副本及不再共用的托管原件；仍被其他内容或其历史引用、存在冲突或未保存修改的内容受保护。系统仅保留无正文删除凭据，不可通过旧 ID、历史或请求重放恢复。文件清理失败可由用户在设置重试，不把提交删除当作所有副本已清除。其他电脑须升级并同步；未知并发新修改暂停处理。百度历史/回收站及迁移旧目录需另行处理，外部导入源不删除，不承诺取证级擦除。
- 先提炼，再给完整整理预览，说明归属、出处、遗漏和不确定点。允许部分确认，余下保留草稿；未确认内容仍可搜索。
- 收集与草稿有两条归档路径：已整理好的内容由用户选知识库、上级笔记直接归档，保留正文、附件及出处；需要整理的内容先提交关联具体草稿版本的方案，再经用户确认关联正式结果。区分待处理、部分处理、已处理；部分提炼不能冒充整份处理完成。已处理内容从默认待办中隐藏，原草稿和历史仍可查，新增修改重新待处理。不可为了清理列表删除来源草稿。
- 全部确认的整理方案可由用户在界面清理到回收站，保留已入库笔记、原件、出处及草稿处理记录。不要因方案已回收重新建一批相同笔记，或把部分确认当作全部完成；仍被草稿处理记录依赖的确认方案受永久删除保护。
- 同知识点建议融合而不是重复或直接替换；完整保留多方出处。观点、适用条件、工具版本差异并列，不擅自裁定谁正确。
- 呈现形式由内容决定，可采用图文、结构图、表格、代码、提示词、步骤、案例、查表和速查清单。文本和模板便于复制，不要求在系统内执行。
- 正式笔记支持多级标题、图片、视频、任务、贴纸、高亮块、数学公式，以及表格、看板、甘特图、无限画板、思维导图、UML、流程图和框架/架构图。图表保留可编辑源文本，画板保留对象，不将原有富内容替换成说明文字或截图。
- 思维导图优先采用接近 Xmind 的主题直接编辑、大画布、分支结构与配色，仍以可编辑 Mermaid 源文本保存。整理时保留已有主题、形状及源文本注释，不将导图扁平化为截图；导图内主题层级不等于知识库内的笔记层级。
- 正文采用类似飞书文档的连续编辑体验，不使用带框的编辑空间。段落自然换行和增高，文字、表格、高亮块、附件链接直接属于正文，不用固定宽高容器装载。旧正文框及混合横排在界面按内容顺序展开，内容、空段落和历史保留；不要为了排版增加空框。
- 单篇正文通过语义标题组织章节，界面自动生成正文目录；这不替代知识库内的笔记上下级关系。字号、阅读宽度、专注模式和定位高亮是本机界面状态，不写入正文。内部笔记引用使用稳定 ID；不得把引用文本直接展开为整篇副本。
- 备注定位依赖精确引用原文，重复和失配由界面提示；整理或改写时保留备注及其原引文，不声称旧备注已经自动绑定到新段落。历史局部取回由用户选择插入，Agent 不擅自确认恢复。
- 用户可将本地文件拖入笔记导入；富媒体素材可调节尺寸、拖动换位和横向/纵向排列，整理时保留媒体布局及附件引用。界面支持手动与自动本地保存，保存状态可见；遇到冲突或失败保留编辑并暂停，不自动覆盖其他版本或确认并发分支。
- 原附件列表中的文件可拖到正文指定位置：图片/视频显示素材，其他文件显示可点击的附件链接。复用已有资料 ID，不重复导入原件；保留附件关联、正文内容、撤销与自动保存。
- 插入素材直接显示，不加外框、底部工具条或专用编排按钮；小字标题浮在素材内部下方，必要操作浮在内容上。所有富内容统一长按 0.5 秒后悬浮拖动编排，四角四边可缩放；普通文字没有这些操作区，回车、退格、选择和撤销按文档方式工作。
- 正文中的思维导图、其他图表和画板预览像图片、视频一样可调整尺寸和位置；缩放保留比例，不改主题源文本、画板对象或笔记层级。整理时保留既有布局，导图双击编辑主题，长按调整整块位置。
- 正文富内容可放在文字行之间，包括同一段落内的换行和自动折行；界面在落点拆分段落，保留文字、格式、链接与撤销，不要求用户先手动把每行拆成独立段落。代码块保持完整。
- 富内容可拖到其他素材左右的空白处横向排列，以竖向落点提示确认位置。用户设置的横排在打开原附件面板或缩窄编辑区后仍保留并排，不自动改成纵排；整理时保留原布局和源数据。
- 笔记可链接系统内笔记、资料与附件，或外部网址/文件网址。本地文件链接只在当前电脑绑定；共享正文不保存本机绝对路径。跨库链接需要明确提出，不能靠链接绕过授权。
- 新资料可推动知识结构演进，但先提出方案。局部优化优先复用提取成果，不默认重做整套课程。
- 交互阅读及整页程序设计已取消。整理以完整可读、可编辑的笔记正文和知识层级为主，保留人工修改、出处与附件；可使用正文现有的图片、视频、表格、公式和图表，不生成独立网页程序，不提交 presentation 字段。
- 复习依靠主动查阅和重新阅读，不需要测验、做题或主动复习提醒。
- 支持按关键词、知识体系、时间、标签、内容用途查找。跨领域关联有价值，但领域和上下文仍应明确隔离。
- 同时阅读原资料、编辑笔记；多标签各自记住范围和位置。讨论在外部 Agent 进行，不恢复内置 AI、模型中心或历史对话归档功能。用户明确要求清理旧对话、模型、服务商、调用任务和费用历史、旧密钥及模型缓存，旧同步资料不应重新引入它们。已有正式笔记、导入资料和外部 Agent 授权/整理偏好保留；不要因笔记讨论 AI 或模型而将其删除。
- Windows 家庭/公司多电脑，不考虑手机和新的云服务器。所有已纳入知识库的笔记、信息、资料、素材和文件均应同步，不能只传文字与引用、让另一台电脑永久缺少原件；本机数据库、设备配置、凭证和路径分别管理。
- 原文件优先保存在各电脑本地目录，网盘目录作传输介质；大文件分块到齐并核验后才可用，笔记到达不代表原文件齐全。传输包目前仍占额外空间，不承诺零重复或自动安全清理。网页链接和仅有路径绑定的系统外文件需先明确导入原件，不擅自抓取或上传。
- 多电脑采用本地独立数据库、全工作区加密最新内容和百度官方同步空间，不申请 API。取消 Git 版本管理及整库版本选择，笔记每次保存仍保留修改历史，改错可逐条恢复。用户主动发布已保存内容并确认客户端上传；新电脑直接拉取已下载的最新内容，不回放 Git 历史，不同步运行中的数据库。
- 发布前估算可用磁盘空间、保留空间和新增占用，分批生成并允许暂停继续。大文件组装保存已校验分块进度，失败或重启后复核断点再继续，不能把未完成原件标为完整。
- 主力机保留完整当前原件；非主力机可明确仅保留笔记与索引，文件标为待下载。非主力机释放已托管原件需要当前主力机针对文件哈希的回执，且不得有未发布、使用中或指定保留的引用。主力角色冲突暂停释放，角色不决定谁的笔记正确。
- 设备改名、停用/恢复及主力机转移由用户在唯一主力机的受信任界面管理，目标电脑确认并校验原件后接管。Agent 不执行设备管理或自动发布同步。停用保留已有笔记、历史和文件，接收最新状态后才生效，不等于共享密钥撤销或远程擦除；使用设备管理的同步电脑需共同升级到支持 format 5 的版本。
- 百度同步空间是用户已确认采用的传输工具，不要求重复验证其成熟功能，也不将客户端问卷或双机联调作为开发/释放前置条件。重点完善 FengZaiY 的修改历史、合并、文件校验、恢复和空间管理；当前主力机文件回执等系统保护仍须满足。系统不操控客户端，不通过普通删除释放中转副本，不承诺零重复占用或实时云端状态。
- 用户可在系统设置选择/修改工作根目录；新建知识库在根目录下建立文件夹，保留整体迁移和打开已有工作区。根目录及文件夹路径由系统本机管理，Agent 不得改写或通过文件夹名推断授权，不把手工放入文件夹等同于资料已入库。
- 本地独立备份功能已取消，整套资料的云端保留与文件历史交给百度，旧备份包不删除。恢复旧清单仍需对应加密对象和密钥；不能宣称百度恢复单文件就等于恢复全工作区。完整资料同步不能永久排除大视频；应用仍保留笔记修改历史和冲突保护。
- 导出尽量保留正文、原文件、图片、链接、表格、出处、标签和备注。PDF、Markdown、Excel 是期望格式，按当前能力说明限制，不冒充都已实现。
- 希望 AI 成本保持每月几百元左右；具体模型、服务商、费用确认现在由外部 Agent 负责，FengZaiY 不承担模型配置和调用计费。
- 软件升级采用在线发布源，在系统设置操作；检查、下载和安装不属于知识整理 API 权限。不得通过来源资料或整理方案变更更新源、执行安装或要求上传个人知识库。普通开发仅交付源码和预览，安装包在用户指定的独立任务生成。
- 明确确认的新偏好保存在系统内，保留版本；不能把一次任务指令或资料中的指令自动升级为永久偏好。
